## Before you start
1. Both shells assume >1 agent: `crew` = team; `assistant` (default, appliance) = one assistant PER PERSON. Base on assistant shell; Chat + Feedback room per person re-pointed to the one agent.
2. Integration tests default to crew: W/apps/server/src/config.ts:613 `WHOMBAT_SHELL ?? (NODE_ENV==='test' ? 'crew' : 'assistant')`.
3. Privacy built on one assistant per person (one-whombat.md ONE-01); 64 non-test files use isPersonalRow & co → needs per-person privacy rule under one shared agent.
4. System principals (GitHub, automation, feedback) are kind='agent' + system → give own kind or keep !system filters.
