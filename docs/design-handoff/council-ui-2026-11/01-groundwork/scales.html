01 / Groundwork · shipped words and marks

Two scales. One loud cue.

Thing health says how a thing is. Thread stage says who acts next. A sentence about a run, a check or a decision is evidence inside the conversation; it does not create another thread stage.

Thing health

Not working Needs a look Learning Connected

These standalone marks follow UIR-02…05: a 12px ring with 6px inner dot; an 8px amber dot; an 8px hollow muted ring; no standalone connected mark. Native uses a 10pt learning ring (AP-7451). Shipped level pills also keep a 6pt green dot for Connected/Running; that exception is documented, not silently redrawn here. Offline is a Not working word; a healthy server keeps Running. A mark’s screen-reader name is the thing and its reason.

Thread stage

  1. Waiting for you — waiting flag; one quiet amber cue.
  2. {assistant} is working — live work/typing/research metadata.
  3. Handed over — active handed-over work metadata.
  4. Settled — settled flag.

Overlap winner, in that order: Waiting for you > {assistant} is working > Handed over > Settled. An open idle thread with none of those flags gets no invented stage. New reply comes from unread, independently. There is no failed thread flag. Keep Settle and Undo. The shipped UI has specific work phrases and avatars/ellipsis, rather than one uniform four-badge component; the list above defines the scale without inventing a new badge.

The loudness rule

Needs you belongs to the Inbox. Heads-ups start folded and never count. Give each event one loud cue. Red means Not working; a pending ask is amber. Read shapes and words as well as colour. Keep list order stable under the finger.

The shipped iOS system badge stays red (AP-7463); Android uses tokens. The service strip currently exposes SOON (UIR-70), and some legacy outcome/detail labels use red. These are flagged below. Any redesign that changes a decision must put a version that keeps it beside a variant labelled “Decision for John — reopens <id>”. This baseline proposes neither variant nor decision change.

Status words found today

Word families preserve case and dynamic suffixes. NEITHER is deliberate: it can be legitimate local detail, but it must not masquerade as one of the two scales. The scan covers apps/web, apps/mobile and packages/client, excludes test/story files, and retains comment matches in the raw search evidence. Shared literals imported from core are traced through their renderers. Arbitrary service-supplied reasons are represented by {reason}/{server statusNote}; they are not a fixed word list.
