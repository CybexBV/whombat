What changes

  1. Two places in the menuServers and Connections sit under Overview. The SERVERS / CONNECTIONS tabs and the row of logos under the menu go away, so the sidebar is the places and your conversations.
  2. A list like Chat’sSame width and row shape as Chat. Each row says how it is doing in a few words. Broken first, then by name; a server that runs on another sits under it.
  3. A problem never hidesThe menu item carries the worst mark of what it holds: a red ring when something is broken, an amber dot when something needs a look. The list’s line under the heading counts them.
  4. Add from the listThe + at the list’s top is “Add a server” or “Add a connection”.
  5. Never an empty right sideOpening Servers shows the one you looked at last, or the first one in the list.
  6. Narrow windows work like ChatBelow 1240 px: first the list, then the page with “‹ Servers” to go back. Try “Window 1100”.
  7. The page’s header is one lineName, a status word only when it isn’t fine, and the buttons. Under it one quiet line of what it is. The address, “Change” and “More detail” move into the ⋯ menu; “‹ Overview” goes, because the list is right there.
  8. A problem is said onceToday UniFi says “AP Paardenstal is offline” four times. Now Worth a look tells it once with its button; elsewhere it is just an amber number.
  9. Two columns in the narrower paneShort cards sit side by side from 700 px of page width, so the page isn’t one long column beside the list.
  10. Overview staysOverview remains the full-width dashboard. A server or tile there opens it in Servers or Connections.
