# Runner API transport refactor — 2026-10-20

| ID | Decision | Reason |
| --- | --- | --- |
| RRA-01 | **Superseded in part by one-person.md OP-S114**: the main runner's typed caller stays; the computer client is gone with `computer-api.ts`. Keep a runner-local typed endpoint caller, using the vendored core endpoint definitions for request params, query, body and response types. Share URL construction, bearer auth, JSON serialization/parsing, HTTP error messages and response validation between the main runner and computer clients. | Removes duplicated transport without changing contracts or adding I/O to core. Endpoint wrappers keep their public signatures and pass lease fields unchanged. |
| RRA-02 | **Superseded in part by one-person.md OP-S114**: the main API's policy stays; the computer API is gone. Make the existing client differences explicit caller policies: the main API keeps `RunnerApiError` with `status`, parsed `body`, `message` and its name, its JSON content type, and its unexpected-202 approval error before schema validation. The computer API keeps an ordinary `Error` with only an added `status`; successful replies, including 202, still pass through its endpoint response schema. | Existing callers can depend on these error shapes and on the computer endpoints' typed `pending` outcomes. Malformed JSON, schema errors and fetch failures continue to propagate unchanged. Only an aborted claim suppresses its failure and returns null. |
| RRA-03 | Keep attachment fetches outside the JSON caller. Preserve their streamed body, size/hash headers, lease query, signal, and text-valued `RunnerApiError.body` on failure. | Attachment bytes must remain unread until their consumer iterates them; their metadata and error behavior differ from JSON endpoints. |

Verification uses focused runner unit tests with injected fetch responses and real Web Response streams. No database or host services are needed: this changes client transport only, with no server write, authorization, signing, event ordering or lease authority changes.
