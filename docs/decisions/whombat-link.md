# Whombat Link (LNK-01…LNK-87)

The Home Assistant model. The box (Whombat, the appliance, the hosts service) is open source and complete on its own;
the cloud (control and the relay) stays closed and sells one thing, **Whombat Link**: remote access without port
forwarding (the box's own address through the door), push to the phone apps, and the apps away from home. €2.50 a
month incl. VAT, the first month free without a card, recommended at setup. The other way in is Tailscale. Pages only
over HTTPS. Every box updates from GitHub Releases, on the Production or Development channel. The admin panel, the
sign-up gate, business billing and the licence go.

**Two phases.** Phase 1 (2026-11) is additive and reversible: it adds Link, the channels and the new setup, and makes
the licence, the editions and the cloud claim inert, so a box can still roll back to the release before it. Phase 2
deletes the dormant code, columns and contracts, after both DEV boxes pass update and restore rehearsals. Production
has no boxes yet; only Home and the DEV stack box move. Design and council reviews: whombat-ops records. Shapes:
contracts 4.4.0 (CT-1756…CT-1766).

Production, the yearly price, promotion codes, free time and the Easy/Expert words: `one-environment.md` (ENV-01…ENV-19).

Phase: **1** is built in phase 1; **1→2** is narrowed or made inert in phase 1 and deleted in phase 2; **2** is later.

## Contracts 4.4.0

Taken while writing the shapes (`docs/contracts/decisions/contracts.md` CT-1756…CT-1766):

- `link.begin` carries the box's full `DeviceRegistration`, so a box control never saw registers by starting Link. The
  manager holds no content key, so the runtime signs the registration's bytes and hands the signature over
  (`LinkOnRequest.contentProof`).
