“Throw away all Whombat skills (including specific Whombat ones like servers, homelab, game servers, support, legal,
sales, etc) and use Hermes Agent skills as the default. We can always create extra skills that refer to Whombat tools if
needed.” Hermes's hub may add more from Hermes's official optional skills, the trusted GitHub repositories and
skills.sh, never ClawHub (his yes to the second question). Use Hermes natively wherever we can.

sign-in, `notion` wants `NOTION_API_KEY` in the Hermes home). Settings → Skills had moved into Settings → Agent with the
