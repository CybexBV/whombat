# Workstream: guided setup in the personal assistant's DM (AG)

Asked for by John on 2026-09-26. Instead of the settings pages and the step-by-step Google panel being the only
way in, the personal assistant opens a conversation in its private DM, offers what it can set up, and guides the
person through it with **interactive cards** (choices with logos, steps with copy buttons, a secure form, a connect
button, a result). Settings stay the source of truth and the fallback; every guide card links to its tab.

John's answers (2026-09-26): a **scripted guide** run by the server, with the AI for free-text questions; **both** the
admin's one-time Google app setup and each person's connect happen in chat; **occasional suggestions** with “Don’t
ask again”; it must work on the **managed stack** (Google connect is enabled there too) and is tested on
dev.whombat.com.

Spans five repos. Each repo records its own decisions in its usual file and cites AG-xx:
contracts `docs/decisions/contracts.md` (CT-80+), whombat-app `docs/decisions/app-managed.md` (next AP-), runtime
here and `managed-runtime.md` (MR-62+), appliance `docs/decisions/integration.md` (IN-47+).

## Topics

`GuideTopic` = `welcome` · `email` · `calendar` · `files` · `briefing` · `google_app` · `repair` (open set in the

files → drive, docs, sheets; contacts stays preticked with the rest.

## Not now

them data; later), a briefing for other agents, guide cards in channels.
