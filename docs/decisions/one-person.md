# One person per Whombat (OP-01…OP-19)

John, 2026-10-25 (main checkout): “a Whombat appliance is being used by one person, it's a personal device. So the
‘Several people share one agent’ rule is false, we should remove that. One person uses Whombat and thus one person uses
Hermes Agent.” Earlier the same day: “Since we started using Hermes agent, I don't see any benefit of using a personal
computer for the agent, so I would like to remove it entirely.” Whombat is not released, so nothing is kept for
compatibility (hermes-engine.md HE-27).

Decided, not built. The inventory of what goes, by repository and file:
`docs/implementation/one-person/inventory.md` (2026-10-25), for John's green light. Research behind OP-04: `~/.cache/wb-tmp/research/2026-10-25-no-computer/notes.md`.
