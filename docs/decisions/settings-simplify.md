# Settings simplified: the runtime's copy (SS-W01…SS-W05)

John, 2026-10-04, approved whombat-app `docs/decisions/settings-simplify.md` (SS-01…SS-30): Settings has six tabs —
Profile, Notifications, Members, AI (sign-ins, organization keys, AI clients, Usage, Spend), Connections (GitHub with
its repositories, Google, Website feedback), This Whombat — and Skills & packs moves to the Agents page (“Agents →
Skills”, `/agents?tab=skills`). The Vault is its own page (`/vault`) since the settings-sidebar change. This file is
the runtime's side: every place outside the app that names an old Settings tab.
