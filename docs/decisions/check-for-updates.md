# Check for updates (CFU)

John, 2026-11-25: a release put in Beta reaches a box only at its next hourly look at the release list. Asked whether
boxes could be pinged, he chose: “Keep it hourly, but add the check for updates button.”

| Id | Decision | Why |
| --- | --- | --- |
| CFU-01 | **The box still looks for a newer release once an hour by itself.** Nothing pings boxes; nothing polls more often. | John's choice: no more traffic to the release list or control, and no new path from control to a box. |
| CFU-02 | **“Check for updates” makes the box look now.** In This Whombat → About → Updates, on the first row (“Up to date · Software …”) where nothing else is to be pressed there: “Check for updates” on the web, “Check” on the phone (read as “Check for updates”). The runtime asks its manager (`appliance.update.check`, the manager's `/v1/update/check`), which looks exactly as at its hourly look — a box with a channel reads the release list and offers the channel's newest again, one without asks control for its assignment — and takes what it finds as any update. Where “Ask before updating” is on, a version found still waits for the owner's yes. Shown from session minor 13 (`UPDATE_CHECK_MINOR`). | A way to have a release now, on the box in front of you, without changing how every box updates. |
| CFU-03 | **What the person is told** (a toast, then the updates' rows follow by themselves): “You’re up to date.”, “Found a new version. It’s on its way.” (“… It waits for your yes.” where they asked for that), “Nothing newer than the update already on its way.”, “Found a version this Whombat won’t install.” A box whose manager can't check yet says it can after its next update and looks once an hour until then; a release list or control out of reach: “Couldn’t check for updates just now. Try again in a little while.” | One short line each; the rows under it show the rest. |
| CFU-04 | **Pressing again doesn't check again.** The manager runs one check at a time; a check asked within 30 seconds of the last one answers that one. | An owner pressing the button again and again mustn't turn into requests to the release list or control each time. |
| CFU-05 | **The assistant may check too** (`change`: “Check for updates now”). | It only does sooner what the box does each hour; what waits for the owner still waits, and installing one stays the owner's (ask-before-updating.md ABU-06). |
