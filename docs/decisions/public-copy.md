# Working in public

Whombat's repositories are public and their maintainers work in them directly (John, 2026-11-15; design
“Work in public from launch”). This file says how; the appliance (`APC-nn`, `appliance/docs/decisions/public-copy.md`) and the hosts service (`HPC-nn`,
`hosts/docs/decisions/public-copy.md`) follow it with their own differences.

| # | Decision | Why |
|---|---|---|
| PUB-01 | **The public repositories are the real ones from launch**: each starts with one root commit whose tree is the cleaned private `main`, and from then on everyone commits there. The private repositories become read-only archives (`CybexBV/<name>-archive`) that keep the old history; no old commit, message, author, branch or tag reaches the public one. | John, 2026-11-15: work in public from the start instead of publishing snapshots of a private repository. |
| PUB-02 | **The root commit is made from `main^{tree}` with `commit-tree`**, hooks and global configuration off, by `Whombat <noreply@whombat.com>`. Later commits are ordinary ones, made with the maintainers' noreply identity (PUB-14). | The tree is exactly what was checked; nothing of the private history is in it. |
| PUB-03 | **Everything that helps someone work on the code is public, cleaned**: the guide for coding agents (`CLAUDE.md`, `AGENTS.md`), the decisions (`docs/decisions/`, `docs/app/decisions/`, `docs/contracts/decisions/`), the implementation notes, the product spec and design references (`docs/design-handoff/`). What only Cybex needs lives in the maintainers' private whombat-ops: their machines and shipping (the maintainer guide), the private guard list and its stand-ins, run records, evidence and audits, the design councils' machine records, the old GitHub-runner CI. `docs/decisions/archive/` and `docs/history/` stay in the private archive. | Contributors need the reasons behind the code; Cybex's operations and records describe its own machines. |
| PUB-04 | **Private values are kept out of the source, never rewritten after the fact**: stand-ins replace them (fixtures use `10.100.0.0/16`, `203.0.113.0/24`, `2001:db8::/32`, `example.com`), and the maintainers' private guard list (addresses, tailnets, device ids, domains, logins, the old tracker's name) is checked at lint (`scripts/check-forbidden.sh`, every rule), at every commit and push by their hooks, in release artifacts (`scripts/scan-artifacts.sh`) and by their guard watch on the public repositories. | A value that reaches a public commit can't be taken back. |
| PUB-05 | **`README.md` is the public README**: what Whombat is, what is in this repository and what isn't (the cloud services, the operator panel), how to run a community box from source. | There is no second, private README any more. |
| PUB-06 | **Secrets: gitleaks and trufflehog** scan every pull request and push to `main` in public CI (pinned versions, checksums checked, `--no-verification`), and the maintainers' push hook runs gitleaks over every push; any finding stops it. Their allowlists (`.gitleaks.toml`, `.trufflehog-exclude.txt`) name reviewed files one by one, never a pattern such as “all tests”. | Two scanners with different rules catch more; a candidate secret is never sent to the service it would belong to. |
| PUB-07 | **Pictures are read too**: the maintainers' push hook reads the changed pictures with tesseract (cached by content in `~/.cache/whombat-public-ocr`) and checks the guard list against the reading, ignoring case and spaces; the weekly full scan reads every picture. | Screenshots show fixture data; a real address in a screenshot is as public as one in the code. |
| PUB-08 | **The scanners fail closed**: only exit 0 with an empty report passes. A “secrets found” exit with a report that lists nothing, an unreadable report or any other exit stops it. | A scan we can't read is not a clean scan. |
| PUB-09 | **The guard list and its tooling live in whombat-ops, outside the public tree**: `scripts/guards.sh` finds the list (`WHOMBAT_GUARDS`, `git config whombat.ops`, `~/Code/whombat-ops`); without it the public checks skip quietly (contributors, public CI), and the maintainers' release tools refuse (`WHOMBAT_GUARDS_REQUIRED=1`: `publish:apk`, `publish:ios`, `contracts:release`, `app:release`, the appliance's `release/ship` and candidates). | A public rule would republish the private values themselves. |
| PUB-10 | **Notices are checked in public CI**: `pnpm check` runs `pnpm notices --check`, so `THIRD_PARTY_NOTICES.md` must describe exactly what the tree holds. | The tree is what is published. |
| PUB-11 | **Cybex BV holds the copyright**: `LICENSE`, `README.md`, `CONTRIBUTING.md`, `TRADEMARKS.md` and `THIRD_PARTY_NOTICES.md` (and its generator) name Cybex BV, not John Pals. | John, 2026-11-15. The company makes and sells Whombat, so the code, the marks and the contributor agreement belong with it. |
| PUB-12 | **Pull requests are merged directly in the public repository**, under the contributor agreement (`CONTRIBUTING.md`, `docs/legal/contributor-agreement.md`), once `public-ci` and the maintainers' `guard` check pass. | John, 2026-11-15. No snapshot in between any more. |
| PUB-13 | **The operator panel lives with control, in the private whombat-cloud repository, which deploys it** (`admin/` there, its decisions in its `docs/decisions/admin.md`). This repository has no `apps/admin`: no panel scripts, Biome scope, lockfile importer, notices fonts or `admin/` in `pnpm app:release`. The panel builds against the contracts release, which packs `@whombat/tokens` and `@whombat/brand` too (contracts CT-1741). | John, 2026-11-15. The panel is Cybex BV's tool for running Whombat's cloud for customers, not part of what a person runs; it deploys with the service that serves it, and nothing here needs filtering for it. |
| PUB-14 | **Commit identity**: maintainers and their agents commit with their GitHub noreply address, set in each clone by whombat-ops `install.sh`; the push hook refuses any other committer address and any author or trailer address the guard list matches. | A company address is a private value. |
| PUB-15 | **Maintainer instructions load from whombat-ops**: its hooks write the maintainer guide into every checkout and worktree as `CLAUDE.local.md` (Claude) and `AGENTS.override.md` (Codex: the public `AGENTS.md` plus the guide), both git-ignored through `.git/info/exclude`; `doctor` repairs a checkout made with hooks off. They are files, not symlinks: Claude resolves a symlinked guide's imports next to the link. | The public guide is for everyone; how Cybex ships is not. |
| PUB-16 | **Public CI runs only on GitHub-hosted runners** (`.github/workflows/public-ci.yml`: no secrets, a read-only token, actions pinned by commit, never `pull_request_target`). Cybex's own CI (ci-platform, fast-test) reads its jobs from `ci/platform/`, which GitHub doesn't run, and never runs a fork's pull request. | Outsiders' code never runs on the maintainers' machines. |
| PUB-17 | **The texts say what is registered**: the name “Whombat” is filed as an EU trade mark (pending); the logo, the mascot and the app icons are marks in use, not registered. `docs/legal/name-and-marks.md` (version `2026-11-20`), `TRADEMARKS.md` and the website say so instead of “registration pending” for all of them. The accepted terms (Appliance Terms, Terms of Service) keep “(registration pending)” until the lawyer's review changes them in one new version. | Only the word mark was filed; a new terms version for one parenthesis would make everyone accept the terms again. |
| PUB-18 | **The demo world names no real machine** (2026-11-20, before the phone apps' public testers and Apple's reviewer see it): the fixture servers that carried the names of the maintainers' own machines are `thetitan` (“The Titan”) and `the-falcon` (“The Falcon”), with the same length and spelling forms as before, in the app's fixtures, the mocks, the tests, the contract vectors and the docs; other made-up names (`blackbox`, `pve-02`, …) stay. The visual baselines and the README pictures were taken again; older design pictures (council rounds, handoffs) have the new name painted over the old one. Docs that named the maintainers' machines as places (where a measurement ran) use the same made-up names. | The demo is public now and nothing in it should point at a real machine; same-length names keep layouts, sorting and tests as they were. |
| PUB-19 | **The demo world names no real person, customer or their machines, and no real-looking domain** (2026-11-20): only Cybex's own public domains (whombat.com, whombat.app, box.whombat.app), its GitHub organisations and well-known services stay. A customer's machines became `arnica-prod-nest-01`, `arnica-prod-db-01`, `arnicabr0` (“Arnica production nest”); a customer school became “HollowMere College” (`hollowmere`, `tfr_hollowmere21`); the mock company's addresses are `burrowhq.example`; personal and shop domains on real top-level domains became `.example` ones (`okafor.example`, `smith.example`, `hollowmere.example`, `bakkerijdevries.example`, `shop.example`, `old-blog.example`, `firm.example`, `banjo.example`). Fixtures, mocks, tests and docs changed together; pictures were taken again or painted, as for PUB-18. Made-up people (Mara Okafor, Joris de Vries, Anna de Vries) and mail providers' domains in tests of provider detection stay. | Customers and their machines are private, and a real-looking domain could belong to someone; same-length names keep layouts and sorting as they were. |
