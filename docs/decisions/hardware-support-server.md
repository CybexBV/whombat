# Better hardware support: the server

Decisions the server stream (S) made building hardware-support.md (HD-01…HD-11) from the build brief
(`docs/implementation/hardware-support/assignment.md` §2, §3 “S”). Contracts: 0.102.0 (the lead, 2026-10-20: on top of
desk-auto's 0.101.0). Code: `apps/server/src/managed/` — `host-hardware.ts`, `host-network.ts` (the services and the
session ops), `host-calls.ts` (what they share), `manager-client.ts` and `ports.ts` (the calls), `fake-host.ts` (the
fake box); `apps/server/src/desk/network.ts` (the screen's routes).

| Id | Decision | Why |
|---|---|---|
| HD-S01 | **Built against §2's shapes first, with a local stand-in, then contracts 0.102.0** (merged from `hw`): the stand-in is gone; the Wi-Fi shapes come from `@whombat/protocol/session`, the manager's and the desk socket's bodies from `@whombat/control-contracts/local`. `host.hardware` and `host.network` are in `IMPLEMENTED_FEATURES` (code-level, like `host.metrics`: a managed runtime advertises them, an older manager answers `unavailable`). | The brief's order of work; contracts 0.102.0 were being made at the same time. |
| HD-S02 | **`host.hardware` hands the manager's report on as it is**: nothing kept, nothing changed, owners only. The manager gets **10 s** for it, not the measurements' 2 s. | The manager collects it when asked (a sysfs walk, hwdata lookups, the helper's kernel log), not from memory; a report the owner asked for once is worth waiting a few seconds for. |
| HD-S03 | **The manager calls**: the network state in 2 s (the manager answers from memory, and the app polls it every 2 s while a change runs), a scan, a join and a forget in 15 s (a forget runs through the same guard as a join), answers up to 256 KiB parsed with the contract. Each service caps the whole call, not only the socket's idle time (as BS-D04). | The brief's numbers; a forget that cuts the box's network needs the guard armed first, like a join. |
| HD-S04 | **Reads never throw**: a manager that is older (404), slow or answers outside the contract is `unavailable`, logged at most once a minute per kind (network state, scan, change, report) with its status and code only — never a request body and never the manager's error text. A scan's `no_wifi` is a `reason`, not a warning. Without a manager the reads say `not_managed` and the changes `not_implemented`; members get `forbidden`. | A poll every 2 s must not fill the journal; a passphrase is in one body and must never reach a log. |
| HD-S05 | **Changes**: the runtime asks for `confirmTimeoutSec: 120` (HD-06's 2 minutes) and checks the passphrase before the manager does (`invalid_passphrase`). A name must also pass `ssidValid` (32 bytes). The manager's codes become `WIFI_ERROR_STATUS`'s generic ones with the network's own in `details.code`, as `desk.*` does (`no_wifi` → `not_allowed`, `busy`, `in_use` → `conflict`, `not_saved` → `not_found`, `invalid_passphrase` → `validation_failed`); a 404 without one of them is `unavailable` (“It needs an update.”). The manager call is an external effect (`manager.wifi.join` / `.forget`, not idempotent): a 4xx or a socket nobody listens on did nothing, a timeout may have acted, so the session answers an unknown outcome and the app reads `host.network`. | The guard's window is HD-06's; the codes as the desk's (CT-525); the ops are `never` in `OPERATION_SAFETY`, which is what an effect before the commit needs (CS-08). |
| HD-S06 | **Every change the manager took is one signed event in the appliance's audit chain**: `network.wifi_joined` or `network.wifi_forgotten` (the lead, 2026-10-20: added to `APPLIANCE_EVENT_TYPES` in 0.102.0), payload `{ssid, via: 'app' \| 'screen', changeId}`, in its own transaction once the manager answered. The actor is the owner's account and device, or none from the box's screen. A refusal writes nothing; an entry that can't be written is logged as an error and the change is still answered (it runs anyway). | The box's network is the box's, like the claim, owners and the backup destination, not one burrow's; neither log had a fitting command, so the brief's “if there is one” became an additive contract change. |
| HD-S07 | **The screen's routes live in `desk/network.ts`** and join the desk socket through `DeskRoutes` (asked before the desk's own routes; the socket only exports `send`/`readJson`). The rule is `deskMayChangeNetwork`: unlocked (`DeskLock`), not claimed (`TrustService.isClaimed`) or not online (the manager's `online`); otherwise `why: 'locked'`. A join or forget decides again with a fresh `networkState()` (never the console's cached answer) and gets 409 `locked` before the manager is asked; a claimed box whose network can't be read doesn't let a locked screen change it (503). A change from the screen keeps an unlocked screen unlocked. Scans always. Codes: `no_wifi`, `busy`, `in_use`, `locked` 409; `not_saved` 404; `invalid_passphrase` 400 when only the passphrase is wrong; `unavailable` 503. Unpaired screens get the same answers. | Its own file and a one-line hook keep the merge with desk-auto (which changes the socket's unlock) easy; the rule is pure so it is tested as a table; deciding again stops a screen acting on a state from before the box came back online. |
| HD-S08 | **The fake box** (`managed/fake-host.ts`, behind `FakeManager.host`): a Flow Z13-like report (MT7925 `14c3:7925` on `mt7925e`, two HD-Audio cards and the `acppdmmach` microphone card, Radeon 8060S `1002:1586` on `amdgpu`, an NVMe disk, `BAT0`, an RTL8153 adapter on `r8152`), a cable, and six networks: Home, Office (saved, in use), Attic (hidden), Café Lumen (open, no internet), Cybex Corp (company), OldRouter (WEP). A change advances on the clock it is given whenever it is asked: `applying`, then a wrong password, a network not found, a company or WEP network or no address fails; else connected and saved, `confirming` only when the box reached Whombat before (MG-15), then `committed`, or `reverting → reverted` with `no_internet` back on the earlier network. The manager's statuses: 400 `invalid_passphrase` for a passphrase to an open network or none to a secured one it hasn't saved, 409 `busy` (one change at a time), 404 `not_saved`, 409 `in_use`, 409 `no_wifi` (`wifiMissing`), and a 404 manager (`older`). Every state passes `hostNetworkValid` (the card's `ssid` while connecting, a `failure` exactly when undone, no `previous` without one). An ended change stays 60 s. It records what was asked without the passphrase. | Tests and the dev world show every phase and refusal without iwd or a radio, and step time instead of waiting. |
| HD-S09 | **A `reason` only when there is no value** (`{network}`, or `{network: null, reason}`), as contracts 0.102.0 have it (`reason?`), unlike `host.metrics`' `reason: null`. | The contracts' shape. |
| HD-S10 | **A desk path no route answers is 404**: the socket's switch ends in a `default`, so a network path on a socket built without the network's routes is refused instead of left without an answer. | The network paths are in `DESK_PATHS` now, so the socket counts them as its own; only `boot.ts` adds their routes. |
