# Decision ids stay findable (DID-01…DID-04)

Code comments and docs cite decisions by id, and agents look them up before they change anything. The architecture
council review of 2026-11-09 found ids defined in two decision files (prefixes two workstreams both used, such as
`CS-` in `chat-settle.md` and `command-safety.md`) and ids cited in code that no doc has.

| ID | Decision | Reason |
|---|---|---|
| DID-01 | **One decision file defines each id** (a table row's first cell or a heading, in `docs/decisions`, `docs/app/decisions` or `docs/contracts/decisions`; archives and specs that quote ids don't count). A new workstream picks a prefix no other file uses. | A reader who looks an id up finds one decision. |
| DID-02 | **An id cited in code is in the docs**: written there, inside a range (`OT-01…OT-12`), or as the decision a lettered id (`SG-15e`) belongs to. A token counts as an id only when its prefix is a decision prefix, so `UTF-8` and `SHA-256` aren't. | A citation nobody can look up only costs the reader. New code cites no decision codes at all (CLAUDE.md); this keeps the old ones honest. |
| DID-03 | **Clashes are renamed, citations a ratchet** (`scripts/decision-ids/`, part of `pnpm check`): no id is defined twice (DID-04), so any clash fails the check; the citations nobody can look up yet are listed in `baseline.json`, anything new fails, and an entry that is fixed must leave the list. `pnpm decision-ids` prints what changed, `--write` rewrites the list. | A clash misleads every reader of the id, so each was resolved once; a citation in a test's name or in data stays until its code changes. |
| DID-04 | **Where the clashing ids went** (2026-11-12): the side with fewer citations took a prefix of its own, and every citation that clearly meant it moved with it: agent-repos.md AGR-, agent-search.md ASR-, chat-settle.md CHS-, concise-replies.md CNR-, crew.md CRW-, feedback-sources.md FBS-, health-run-start.md HRS-, licence-notices.md LNC-, managed-sandbox.md MSB-, merge-own-account.md MOA-, message-polish.md MPO-, person-avatars.md PVA-, pg-guard.md PGG-, preview-security.md PRS-, runs-approvals.md RAP- and MDS-, search-pagination.md SRP- (the app's SP-11…SP-14 too), share-links.md SHL-, shared-passkey.md SPK-, visual-regression.md VRG-. stack-optimization.md's RF-03 is OPT-01, the app's open-speed.md AP-4410…AP-4413 are AP-9190…AP-9193, and the app's AP-678…AP-691 live only in its own resourceful-agents.md. | `docs/history/`, archives, other repositories and test names keep the old ids; this row turns one back into its file. |
