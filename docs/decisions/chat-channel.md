# Chat: one threaded room with your assistant, Feedback beside it, Home becomes Dashboard (2026-10-18)

John, 2026-10-18 (main checkout): “I wish to bring back the chat, but only as a single channel. When we click on “Chat”
it should show the channel directly and all messages should be threaded inside that channel. So when I ask something,
Dusty should reply in a [thread]. This “Chat” channel will be the default for all conversations with Dusty. […] when
opening Whombat (web UI or Android app) this chat should be the default entry. Rename “Home” to Dashboard.” After the
proposal and mockup (`whombat-app/docs/design-handoff/chat-channel/index.html`) he answered: **private** per person;
**clear all existing chats so we start fresh**; a **separate Feedback** entry in the sidebar, a dedicated room for
it; **open the thread** after sending; “I agree with your whole proposal.”

This replaces task chats (one-whombat.md ONE-06, one-whombat-assistant.md ONE-DW14…DW16) in the assistant shell. The
crew shell is unchanged. Versions: contracts **0.93.0** (CT-440…469), whombat-app **0.91.0** (AP-2400…2499), migration
**0116**, appliance candidate **0.102.0** (IN-294, rc.124, pve-20261018.18 unless the peer says otherwise). DEV only.
