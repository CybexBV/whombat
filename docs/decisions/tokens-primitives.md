| # | Decision | Reason |
|---|---|---|
| TP-01 | **Storybook 10** (`storybook`, `@storybook/react-vite` ^10.6) instead of 9. | Storybook 9's Vite builder supports Vite ≤ 7 only; the repo uses Vite 8. The config API is the same (`.storybook/main.ts`, `preview.tsx`). Docgen is `react-docgen`, because TypeScript 7 has no JS compiler API for `react-docgen-typescript`. |
| TP-02 | Theme color CSS variables keep the reference names (`--bg`, `--side`, `--sf`, `--sf2`, `--ink`, `--ink2`, `--mut`, `--line`, `--line2`, `--brand`, `--btn`, `--btnfg`, `--code`, `--ok`, `--warn`, `--bad`, `--sel`, `--ov`, `--hi`, `--mark`, `--mark2`, `--bubble`). Everything else is prefixed: `--font-*`, `--type-<name>` (font shorthand) + `--type-<name>-tracking`, `--radius-*`, `--space-<px>`, `--shadow-*`, `--max-*`, `--size-*`, `--bp-*`, `--duration-*`, `--z-*`, `--code-*`, `--status-*`, `--tone-1..5`, `--role-<role>` / `--role-<role>-deep`, `--fur-<fur>[-muzzle/-inner/-brow]`, plus `--presence`, `--live-halo`, `--progress`, `--knob`, `--on-solid`, `--avatar-ink`, `--placeholder`. | Inline styles from the mocks port 1:1. |
| TP-03 | `tokens.css` is generated (`pnpm --filter @whombat/tokens generate`) and committed. A unit test fails when it is stale. The generator writes Biome's format (`rgba(0, 0, 0, 0.4)`, `44px / 1.02`), so the file passes `biome check`. | Single source of truth in TS, no build step for consumers. |
| TP-04 | Light is on `:root` and `[data-theme="light"]`, dark on `[data-theme="dark"]`. No `prefers-color-scheme` media block in CSS: an inline no-flash script (Vite `transformIndexHtml` plugin, `NO_FLASH_SCRIPT`) sets `data-theme` before first paint. The rule is: stored choice (localStorage `whombat:theme`), else `prefers-color-scheme`. While no choice is stored, the page follows live system changes. | Matches the spec. Any subtree can also force a theme with `data-theme` (the tokens story renders both themes side by side this way). |
| TP-05 | Per-user server preference: `useThemePreferenceSync(serverPreference, save)`. A server value, once loaded, wins and is written locally. User toggles call `save`. The shell/auth workstream wires it to the user profile. | Keeps the theme logic independent of the API. |
| TP-06 | Button sizes follow the mock instances: `xs` 6×13 r9 13.5px (composer Send), `sm` 7×12 r10 13.5px, `md` 8×14 r10 14px (default), `lg` 9×16 r10 14px, `xl` 11×18 r12 15px. `padX`/`padY` override padding for the few wider primaries (11×20, 12×22). Primary has **no border** and secondary a 1px `line2` border, exactly as in the mock, so a primary is 2px shorter than a secondary with the same padding. Variants: primary, secondary, ghost (mut text), link (brand 600, no padding). Disabled = sf2 fill + mut text + `not-allowed` (the mock's "Merge into main"). | Pixel parity: the roster "Hire an agent" button, "Export CSV", the hire modal actions, the segmented control, the kind chips and the toast all diff at 0.00% against the reference at 2× in light and dark. |
| TP-07 | No hover fills on buttons, chips or icon buttons (the mock has none). Ghost and link buttons darken to `ink` on hover, like the reference `a:hover`. | Mocks win on visuals. |
| TP-08 | Focus: global `:focus-visible { outline: 2px solid var(--brand); outline-offset: 2px }`. Inputs use a `brand` border plus a 1px `brand` ring instead. The segmented control shows the ring on the focused item. Modals focus the dialog itself on open (not the first control), so nothing is ringed until the user tabs, as in the mock. | The mocks have no focus styles; CLAUDE.md requires visible focus. |
| TP-09 | SegmentedControl is built on native radio inputs inside a `fieldset` (arrow keys and form semantics for free). Chip is a toggle button (`aria-pressed`). RemovableChip is the "Only Banjo ×" filter. | Accessibility without custom key handling. |
| TP-10 | Toggle = Radix Switch (36×22 `md`, 34×20 `sm`, 16px knob `--knob`, 150ms). `ToggleRow` is the hire-modal key row: the whole row is a `<label>`. Locked rows are disabled, forced off, 50% opacity, and show a mono note, which is linked as `aria-describedby`. | README Toggle and the hire modal. |
| TP-11 | Toast: `ToastProvider` + `useToast().show(message, {duration})`. One toast at a time (a new one replaces the current one and restarts the 2.6s timer); `duration: null` keeps it up. It sits in a fixed `role="status"` live region, bottom-center 28px, `z-index: 30`. `Providers` includes `ThemeProvider` and `ToastProvider`. | Same as the mock's `flash()`. |
| TP-12 | Modal = Radix Dialog with the Content nested in the Overlay. Overlay click closes it (Radix outside-press), and so does Esc. Widths `md` 560 and `lg` 760. `padded` (default) = 28px padding, 22px column gap (approval modal); `padded={false}` for custom layouts (hire modal). Accessible name via `<ModalTitle>` or the visually hidden `title` prop. | README Modals. |
| TP-13 | SidePane widths thread 400 / agent 380 / branch 340, `surface` bg or side. It is inline at ≥ 1240px; below that it becomes `position: absolute` with `--shadow-pane`, using a CSS media query `(max-width: 1239.98px)`. A test keeps that query in sync with `breakpoints.pane`. Its positioned ancestor must be the app frame (the shell root is `position: relative`). | CSS variables cannot be used in media queries. |
| TP-14 | Icons: **Lucide** (`lucide-react`), 1.75px **absolute** stroke (`absoluteStrokeWidth`), 16–18px, `currentColor`. Screens use named slots from `components/Icon/icons.ts` (`search`, `agents` → PawPrint, `canvases` → FileText, `auditLog` → ScrollText, `channel` → Hash, `close`, `back`, `can`/`ask`/`cannot`, `locked`, composer `mention`/`command`/`attach`/`send`, …). Icons are decorative (`aria-hidden`) unless `label` is set. | README Icons; the mocks' glyph outlines are about 1.7px at any size. |
| TP-15 | `RoleBadge` takes `agentRole` (not `role`, which Biome's a11y lint treats as an ARIA role). Variants `sm` (message row), `md` (DM header), `plain` (roster/profile/hire: 8px dot, 11.5px mut). | Lint-clean, one component for all three mock uses. |
| TP-16 | `Kbd` + `formatShortcut('k')` gives `⌘K` on Apple platforms and `Ctrl K` elsewhere (B-03). | Shared by the sidebar search hint and the ⌘K handler. |
| TP-17 | React Native theme: `nativeThemes.light/dark` (`createNativeTheme`). It merges theme and fixed colors, converts type styles to RN text styles (letter-spacing em → px, line-height → px, per-weight font family names from `@expo-google-fonts`: `BricolageGrotesque_700Bold`, `DMMono_500Medium`, …), and gives numeric radii and spacing, shadows as `boxShadow` strings + `elevation`. | Mobile workstream consumes the same tokens. |
