# One agent per Whombat (OA-01…OA-24)

John, 2026-10-23 (main checkout): “Whombat is NOT using multi-agent anymore, if this is still in the codebase we should
remove it. We shouldn't be able to ‘hire an agent’ anymore”, and earlier the same day “we only use 1 agent in 1
appliance”. Whombat is not released and nobody uses it, so nothing is kept for compatibility (hermes-engine.md HE-27);
John approved wiping his DEV data (HE-29). This is step 0 of the Hermes rebuild (hermes-engine.md): it removes what
exists only because there could be more than one agent, before the engine changes.

Inventory of what is removed, by repository and file: `docs/implementation/one-agent/inventory.md`. Work plan:
`docs/implementation/one-agent/assignment.md`.

Supersedes: agent-handoffs.md (AH-01, AH-02), delegation.md, agent-responsibilities.md, agent-roles.md,
role-consolidation.md, five-agents.md, crew.md, essentials-agents.md, agent-keys-handles.md, ask-agent.md, reply-to.md,
general-welcome.md, assistant-name.md and assistant-name-server.md (names and faces, except OA-08), one-whombat.md ONE-01…
ONE-03, one-whombat-assistant.md, one-assistant-computer.md, connectors-personal-agents.md, and the multi-agent parts of
essentials-people.md, provider-subscriptions.md (SUB-44), feedback.md (FB-24), chat-channel.md, spend.md,
work-supervision.md, skill-store.md, health-checks-wake.md (HW-05). Those files stay as history.
