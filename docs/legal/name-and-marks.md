# The name “Whombat” and its marks

Version `2026-11-20`.

“Whombat”, the Whombat logo, the wombat mascot and the Whombat app icons are trademarks of **Cybex BV**, a company in
the Netherlands. The name is filed for registration as an EU trade mark; the logo, the mascot and the icons are not
registered. They tell people that a product comes from us.

Whombat's source code is free software under the GNU Affero General Public License, version 3 only (AGPL-3.0). That
licence is about copyright and patents, not trademarks, and its section 7(e) lets us say so: **the AGPL-3.0 gives no
right to use the Whombat name or marks.** Everything the AGPL-3.0 allows you to do with the code stays allowed. This
note only says under which name you may do it.

The files of the logo, the mascot and the icons are part of the source code and come under the AGPL-3.0 like the rest
of it. Only their use as marks is limited, as this note describes.

## What you may do without asking

- Use, study, change and share the code under the AGPL-3.0.
- Run Whombat releases you got from us, or build the unchanged source for your own use, and call it Whombat. That
  includes running it without whombat.com, as the community edition does.
- Say truthfully what your software is: “based on Whombat”, “a fork of Whombat”, “works with Whombat”, as long as
  your own name is the product's name and nothing suggests that we made, checked or endorse it.
- Name Whombat in articles, reviews, tutorials, talks, comparisons and security reports.
- Keep technical identifiers that contain the name where changing them would break compatibility: package names
  (`@whombat/*`), Go module paths, file and directory names, protocol strings, environment variables, service and
  user names. People don't see them as the name of a product.

## What a fork must do

If you distribute a changed version, or let others use one over a network, it must:

1. **have a name of its own** that people won't confuse with “Whombat” (not “Whombat Plus”, “OpenWhombat” or
   “Whombat Community”), shown everywhere the product's name appears: the app's title, the web page, the app stores,
   the installer, the box's screen and console, the documentation, domain names and social media accounts;
2. **replace the Whombat logo, the wombat mascot and the app icons** with its own (Whombat's `packages/brand/` holds
   them, and some repositories have copies);
3. **not suggest that we make, support or endorse it**, and not present our support and security addresses or our
   whombat.com service as its own.
