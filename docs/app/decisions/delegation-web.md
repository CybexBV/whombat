# The delegation card on the web (AP-7700…AP-7719)

John, 2026-11-06, after the first real delegation (ten tracker tasks, ten open pull requests, four with failing checks):
the card keeps what needs the person in view (Whombat `docs/decisions/delegate.md` DLG-20…DLG-31), and an `improve`
council builds through one (`docs/decisions/council.md` CNL-60). The contract is core's `DelegationCard`; every word is
`delegationCardView` and `DELEGATION_WORDS` in `@whombat/client`, which the phone shares. There is no mock: the card is
`DelegationCard` (`features/cards`), in the council card's frame and grid (`council-web.md` AP-7620, AP-7621). The
council card's own changes are in `council-web.md` (AP-7715…AP-7717).
