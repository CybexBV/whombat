## AP-2500 Connections, beside Servers

The web sidebar's section under SERVERS, the Dashboard's section after Servers (web and phone) and the crumb on a
connection's or device's page say **Connections** instead of “Your things”; the sidebar's `+` is labelled “Add a
connection”. It is the word people already see where they add one (Settings → Connections, “Add a connection”), and a
device is something a connection found, so it belongs there. The phone's **Things** tab keeps its name: it lists
servers as well (SERVERS, CONNECTIONS, DEVICES); only its load error says “Things didn’t load.”. Code names
(`things`, `ThingsCard`, `home.overview`'s `things`) stay.
