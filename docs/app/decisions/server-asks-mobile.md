# Asks you first on Android (AP-1740…AP-1747)

John, 2026-10-18: “I don't want to give a yes on each command, is there a way to give you full access?” Whombat decides
the setting in `docs/decisions/server-asks.md` (SA-01…SA-09); this is the phone's part: the server page's row (SA-08)
and the approval's “Don’t ask again on {server}” (SA-07). Contracts 0.86.0 (CT-380…CT-382).

| ID | Decision | Why |
|---|---|---|
| AP-1740 | **Where it is**: the phone has no System tab, so “Asks you first” is a card at the end of a server's **Summary**, after ABOUT IT and before “Ask about {server}”: the card's mono label “Asks you first”, the two choices as the app's `Segmented` (38dp, 44dp with its hit slop), the hint under them. | The Summary is where the phone shows what a server is; one card, no new tab for one setting. |
| AP-1741 | **Who sees it**: owners (`hosts.status.canManage`, else the viewer's role), on a Whombat whose runtime has `hosts.asks`. Members see nothing (no read-only row). Before 0.86 a runtime doesn't keep it, so the card isn't there. | SA-05; a row a member can't change and that doesn't affect what they may do adds nothing on a phone. |
| AP-1742 | **The words** are core's `HOST_ASKS_FIRST_WORDS`, verbatim: choices, hints, and on **Never** on the server this Whombat runs on the self note after the hint (“It still asks before restarting or shutting down thetitan, which runs this Whombat.”); on Before risky actions the note isn't shown. The value is the server detail's `asksFirst`, else the fleet row's, else Before risky actions. | SA-03 and SA-08: the note is about Never. |
| AP-1743 | **Changing it**: to Never, the app's alert “Stop asking on {server}?” with the body, Cancel and **Stop asking** (destructive style, as the app's other widening confirms); back to Before risky actions saves at once. It saves `hosts.updateServer {asksFirst}` (nothing else in the body), the choice shows at once and stays until the server's page has it, then the toast `changed`. A refusal shows in the app's alert (“Not yet” for a commit that waits, “That didn’t go through” with the service's words) and the choice goes back. | SA-08: the confirm is for widening only. |
| AP-1744 | **Superseded in part by AP-7407, AP-7408** (phone-refresh-asks.md: apart at the content’s end, behind the platform’s alert, naming the server’s page). **The approval screen**: a `connection_call` with `params.server` keeps Decline / Approve and puts **“Don’t ask again on {server}”** above them, as a secondary button, exactly where a risk row's “Always allow …” sits (core offers it to owners only via `scopeChoices`). It sends `approvals.decide {decision: 'approve', scope: 'agent'}` and shows core's `toasts.always` (“Approved. Whombat won’t ask again on thetitan.”). Not gated on `hosts.asks`: only a 0.86 runtime sends `params.server`. | SA-07; one pattern for “approve and stop asking” on the phone. |
| AP-1745 | **The toast is worked out on the phone** (`scopedApproveToast` in `data/approval.ts`: core's `approvalView(...).toasts.always` for a Servers call with scope `agent`), not through `@whombat/client`'s `approveToastFor`, which only knew risk rows at 0.86. | The web stream owns `packages/client`; the phone stays right either way. |
| AP-1746 | **The demo world** (`fixtures/serverAsks.ts`, in the one-Whombat world): every server starts at Before risky actions; `hosts.updateServer` / `hosts.serverSettings` keep and read `asksFirst`, the fleet and the server page carry it. A chat “Clean up Docker on thetitan” holds Dusty's approval #32 (“Run “docker image prune -a” on thetitan?”, a Servers call with `params.server`); “Don’t ask again on thetitan” approves it, sets thetitan to Never and sends `message.updated`, `approval.updated` and `hosts.server`. | The row and the button render without a server, and the two meet: the card's yes shows on the server page. |
| AP-1747 | **The chat's approval card** stays the summary that opens the approval screen; the button lives on the screen only, like every other scoped yes on the phone. | The phone decides on the approval screen (AP-690, AC-42). |
