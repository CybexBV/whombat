## The first build: Code on the web

The work line (AP-7800…AP-7802), the live cards (AP-7803…AP-7805) and the narrow top bar (AP-7814) are in force.


John, 2026-11-07 (Whombat `docs/decisions/one-chat.md`): “In the thread list we should see if a thread is currently
working … what it's doing and what the progress is in a subtle way”, the council card should show its work and “the
very large button to STOP … should not be this prominent”, software work should move “to a new ‘Code’ screen / menu
item … act similarly as T3 Code”, and on a phone “the hamburger menu on the top left and search on the top right”. The
contract is core's `ChatThread.place`, `.code` and `.work` and `chats.place`; every word and the rows themselves are

in Chat (bottom of the page), only the chat pre-fill text should not say ‘Ask Dusty anything’ but ‘What do you want to
build today?’. Same with settled code threads, show them similarly as in Chat. The settled threads need to be moved the
same as in Chat, but the working and the other sections should function as they do now.” New job and its box go (the
box at the bottom replaces them), settled jobs leave the list for Settled in Code's head, the Done chip goes; Needs you,
At work, Open and their chips stay.
