# the tracker reports through automations (AP-1016…)

John, 2026-10-10: “We have support for the ticket system of the tracker … I think we should use automations instead. I think
this would be a better fit.” the tracker becomes a connection (Settings → Connections), a new report starts an automation,
and a step writes the assessment back; people read the report on the run page and answer the reporter from there
(Whombat `docs/decisions/report-trackers.md` TA-01…TA-21; contracts 0.69.0, CT-325, feature `automations.tracker`).
This is the app side. Without `automations.tracker` every screen stays as it was. No HTML mock exists for these
additions: they follow the simple form, the automation page and the run page (automation-recipes.md AP-966…AP-1015).
