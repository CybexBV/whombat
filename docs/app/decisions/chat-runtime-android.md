# What answers in Chat, on the phone (AP-2715…AP-2749)

John, 2026-10-19: “In the chat with Dusty, we should be able to change: the provider (e.g., OpenAI or Claude), the
effort, fast mode, if applicable.” After the mockup (`docs/design-handoff/chat-runtime/index.html`, section 4 for
Android: the same button above the composer's pill, a bottom sheet instead of the popover): “I love it. Implement this
fully.” Whombat `docs/decisions/chat-runtime.md` CR-01…CR-11 (contracts 0.96.0, CT-456…CT-468; 0.96.1, CT-469: the
Chat box's choice goes with `messages.send`). This is stream M of the build (Whombat
`docs/implementation/chat-runtime/assignment.md`); the web and `@whombat/client` are `chat-runtime.md` AP-2680…AP-2714.
Every rule and word comes from the client (`chat/runtime.ts`, `react/chatRuntime.ts`, `modelEffort.ts`) and the
contracts (`text/chat-runtime.ts`, `text/models.ts`); the phone adds only how it draws them.
