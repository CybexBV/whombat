# An agent's model and effort (AP-1128…)

John, 2026-10-10: “We have different agents that we can configure with a provider (Claude or Codex), but we cannot set
the model and we cannot set the effort. I would like to be able to configure this per agent.” Whombat
`docs/decisions/model-effort.md` ME-01…ME-07 for the server and the runner; contracts 0.77.0 (CT-333: `AGENT_EFFORTS`,
`AgentModelRuntime.effort`, `ProviderModel` and `ProviderSetup.models`, `modelOf`, `effortsFor`, `turnEffort`,
`AgentProfile.modelFallback`, `text/models.ts` with `EFFORT_LABELS`, `MODEL_EFFORT_COPY`, `defaultModelLabel`,
`modelLabel`, `agentModelSummary`, `modelFallbackText`, feature `agents.model_effort`). This is the app side. Without
`agents.model_effort` every screen stays as it was. No HTML mock exists: MODEL follows Configure's rows with the
connections' radios, EFFORT the provider's segmented control, Android the sheets' radio rows (the tracker, caretakers).

| AP-1128 | **Web: MODEL and EFFORT on Configure → Model & provider**, under AI PROVIDER, for an agent on Claude Code or Codex on a live Whombat with `agents.model_effort` (personal agents too; never the scripted demo or an ACP runtime). MODEL: a radio group named “Model”, a row per choice like Configure's rows (10px 0, the top line, 14.5px; the radio first, 16px in `btn`), “Default (Opus)” first (`defaultModelLabel`, no model), then the tool's list in its order with its own line under the name (“Opus 5.5 · Best for everyday, complex tasks”); the picked one in 600. EFFORT: the provider's segmented control on a row of its own (a radiogroup named “Effort”, wrapping on a narrow page) with Automatic, then the levels the picked model takes (`effortsFor`; all six while the list isn't known; a stored level the model doesn't take shows in its place), and under it “Medium for conversations, high for code work.” for Automatic or “Every turn uses this, conversations too. Higher thinks longer: slower replies and more usage.” for a level. A model that takes no effort has no EFFORT. | One place people already go to (ME-01), in the shapes Configure already has; a model's own line tells people who aren't developers which one to pick. |
