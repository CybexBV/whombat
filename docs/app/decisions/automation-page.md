# An automation's own page, and a list that reads (2026-10-30)

John, 2026-10-30, looking at the new Automations tab on his iPhone Duo: the rows “make no sense”, the switch “has some
weird shade location”; “I’d like to see the name of the automation and when clicked we should see the whole
automation. This view should make sense and show exactly what the automation does.” A mock-up (both phones and the open
Duo) followed, then “Implement this fully”. Phone only; core gains the step-by-step view and a tracker wording fix, so
the Whombat's plan card says the same.

| # | Decision | Why |

## The same list and page on the web (2026-10-31)

John, 2026-10-31: “The Automations page on iOS looks way better than in the web ui. Can we improve the web ui as well?”
The web takes the phone's list and page (AP-6330…AP-6335) with the same words, and uses a wide screen's room by putting
the page's facts beside what happens.

| # | Decision | Why |
|---|---|---|
| AP-6380 | **Superseded in part by docs/decisions/automations-final.md AF-01, AF-06 (“Automations n”, the compact row).** **The web's list is the phone's** (`AutomationRow`): AUTOMATIONS · n, then each row as one link to its page — the 40px tile, the whole name on up to two lines (15.5/600), what starts it (13.5 `ink2`), the status line (a 7px dot, On, Off, Waiting for you or Not on yet, the last five runs as 4×11px bars, the last or next run in words) and a chevron; off and not-on-yet rows dimmed, their status line not. No switch, buttons, ⋯ or sentence on a row. The agent's schedules get their own card under ONLY TELLS YOU, with the same name, when and status lines, Talk about it, Remove and the switch. Supersedes automation-chat.md AP-6214…AP-6216, AP-6219 and AP-6220 on the web. | One look per automation, as on the phone; a row was four lines of buttons and the switch sat where a click meant to open it. |
| AP-6381 | **The web's page is the phone's, in two columns on a wide screen**: AUTOMATIONS, the 52px tile and the name (30/700); on the left the agent's sentence, Try it (primary, or Run now) and Talk about it, WHAT HAPPENS as the phone's rail (core `automationFlow`, the agent's steps with its face, checks dashed, marks with `color-mix` washes) and “What <agent> is asked”, folded with its step count; on the right (320px) the state card with the switch or what waits and Open, ASKS YOU FIRST, LIMITS, RECENT RUNS (the last ten) and Delete automation. A run that needs a look reads “needs you to look at it” on both. Names come from each app's own reads (`useAutomationNames`). | The web and the phone say the same thing about the same automation. |
