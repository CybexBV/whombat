# The assistant's own name on Android (AP-1533…AP-1556)

John, 2026-10-17: instead of “Whombat”, the assistant gets a person's name automatically (Dusty first), which its owner
can change, and the old crew (Dusty, Pippa, Banjo…) goes out of sight (Whombat `docs/decisions/assistant-name.md`,
AN-01…AN-09). This is the phone's part, stream M of `docs/implementation/assistant-name/assignment.md` §5 in Whombat;
the web's is `assistant-name-web.md` (AP-1503…AP-1532). Contracts 0.82.0 (CT-357…CT-360); no contract change. Already on
`an` and used here: `@whombat/client`'s `agentAvatarRole` drawing the face (`agentFace`) and `suggestAssistantName`; and,
since the web stream merged (`an` 833ae560, merged into `an-mobile`), `myAssistantOf`, `assistantWords`,
`assistantFaceLabel`, `listsAgent`, `caretakerChoices(…, shell)` and `useSetAgentModel` putting the saved agent in the
bootstrap. The card follows the mock's screen 5 (`docs/design-handoff/one-whombat/index.html`, `assistant.png`) at phone
width.

The phone's own pure parts are `apps/mobile/src/data/assistantName.ts` (the card's words, model and checks, the
suggestions) and `data/crew.ts` (whose page is whole, the `@` list), both unit tested; the hook `data/useOwnAssistant.ts`;
the card `settings/AssistantCard.tsx`; the demo world's part `fixtures/assistant.ts`.
