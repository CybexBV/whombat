# Connection pages on the web (2026-10-18)

Stream W of Whombat `connection-pages.md` (CP-01…CP-20): every connection and every device gets a page like a
server's, built by the server (`things.page`, contracts 0.88.0, CT-390…CT-393) and drawn here by panel kind. John's
revised mock `ha2.png` is the target for Home Assistant (`~/.cache/wb-tmp/mockups/connection-pages/`); `unifi.png` and
`generic.png` are read with CP-02 in mind (no UniFi client lists, no Home Assistant rooms). Less-is-more's rules
(AP-1749…AP-1755) apply. The phone is stream M's (`connection-pages-mobile.md`, AP-1950…).
