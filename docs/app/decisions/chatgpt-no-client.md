# ChatGPT is a sign-in, not a client (AP-5610…AP-5624)

Whombat `docs/decisions/hermes-native.md` HN-02…HN-04 (John, 2026-10-25): ChatGPT turns run on Hermes's own loop
(Hermes's `openai-codex` provider), ChatGPT signs in through Hermes's device-code login, and the Codex CLI leaves the
runtime (HN-C08). HN-C08 leaves the client list to the app: “dropping it is the app's (no Codex row, no auto-install)”.
The runtime's side is in the same file's `HN-A` rows (`clients.list` lists Claude Code only, `clients.install` refuses
`codex`, onboarding's picks install only Claude Code, a box's leftover Codex client is removed). The runner's
`ProviderCheck` for `codex` is `ready` with `version: 'Hermes <v>'` whenever Hermes is (HN-C07). Claude Code stays an
installed client (DirectSDK and `claude auth login` need it). People read the provider as “ChatGPT”; the provider id stays
`codex` in the contracts and the API.
