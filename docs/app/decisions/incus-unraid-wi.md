# Full Incus support and the self guest — the web (stream WI, 2026-10-17)

Stream WI of the Incus and unRAID build (Whombat `docs/decisions/incus-unraid.md` IU-01…IU-12; brief
`docs/implementation/incus-unraid/assignment.md` §3 WI): the Incus server page, the Incus instance page, the Incus
create dialog and the guest this Whombat runs in, everywhere on the web. Built to contracts 0.83.0 (merged 0.84.0 with
WU). The Proxmox pages (`proxmox-wa.md` … `proxmox-wd.md`) are the pattern: cards, tables, the review step, toasts with
Show progress.

## Contract gaps (told the lead)

- `config.get` says a key is inherited but not from which profile: rows say “From a profile”.
- `HostBackupVolume` has no `instanceOnly`, so a backup can't say whether it holds the snapshots; and there is no way
  to ask for a backup that never expires (null `expiresAt` isn't defined), so the dialog doesn't offer it.
- `HostIncusImage` doesn't say where an image updates from, so Refresh is offered for cached or auto-updating ones.
- `HostChoices.bridges` lists the networks a NIC can use without saying which are Incus's own; the NIC dialog treats
  them as Incus networks and asks for a server bridge by name.
