# Hermes as the only engine on the web, the phone and in the shared client (AP-5000…AP-5199)

Whombat `docs/decisions/hermes-engine.md` step 2 (HE-01, HE-03…HE-15; HE-31 keeps the Chat runtime picker, HE-32 adds a
model on the owner's network): every turn runs on Hermes, so the ACP runtimes, the capability matrix, the scripted demo
agent (`WHOMBAT_AGENTS`) and their words go from the app; owners can point the Whombat at a model server on their own
network. Contracts 0.124.0 (CT-1150…CT-1179, `docs/hermes-engine-api.md` there). Nothing is kept for compatibility: the
product is unreleased (HE-27). Hermes isn't something people see: its readiness reaches them only in the contracts'
words (`ENGINE_PROBLEM_COPY`). Numbers: client AP-5000…AP-5039, web AP-5040…AP-5119, phone AP-5120…AP-5199.
