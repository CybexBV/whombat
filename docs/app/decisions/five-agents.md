### AP-655 The hire rows describe, they don't list skills (whombat-app 0.28.1)

John, looking at the picked Associate on 0.28.0: “Remove the skills, and extend the description a bit.” The five-role
picker's rows no longer list the picked role's packs and skills (RO-46's SKILLS list under the row is gone); the packs
are still pre-ticked and editable on the Name and keys step. Each row's description is the role's “What it does”
(`ROLE_JOBS`) plus one sentence on how it works (`roleDescription`, `features/agents/roleDescriptions.ts`): app copy,
not a contract, because only the picker shows it — `ROLE_JOBS` stays the hire's job line and the prompt's “Your job:”.

### AP-661 Retired agents hold no name in the hire screen (whombat-app 0.28.3)

Whombat five-agents.md FA-17: on a runtime with `agents.fixed_names` the hire rows' names (`hireName`, and the legacy
picker's `hireRowNames`) count only active principals (`isActivePrincipal`), as the runtime now does, so after Banjo
retires the Software Developer row offers Banjo again. Against an older runtime every principal still counts.
