# All skills: Settings → Skills (2026-10-18)

John, 2026-10-18: “We currently have Skills in the sidebar, I think we can remove that and add a new section in Settings
where we can list / edit skills?”, then “Implement this fully.” Product decisions: Whombat `docs/decisions/all-skills.md`
(SK-16 the tab replaces the sidebar row, SK-17 the tab, SK-18 the phone); contracts 0.92.0 (CT-410…CT-420, the library
REST surface is CT-415 `api.skills.library*`, `importPreview`, `importCommit`, `hubSearch`); the mockup John saw is
`docs/design-handoff/all-skills/settings-skills.html` (layout, order and words; the app's tokens and component sizes win
on details, its figures are made up). Web and client: AP-2300…AP-2359 (stream W); the phone: AP-2360…AP-2399 (stream M).
