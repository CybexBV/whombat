## Contract notes for the lead and stream HQ

- `content.list` with `platform: libvirt` is read as `{volid, name, sizeBytes, usedBytes?, format?, usedBy?: string[] (guest ids), created?}`;
  without `content` it lists every volume of the pool, with `content: iso` only images. 0.84 types `items` as JSON objects.
- `volume.create` sends `format` (`qcow2`/`raw`) besides `pool`, `name`, `size` (`20GiB`); `disk.resize` sends `size: "+8G"` as on Proxmox.
- `content.delete` sends `volume` = the image's `volid`; `backup.restore` / `backup.delete` send `guest` as the list gave it (name or id).
- A NIC that isn't on a network or bridge is read from `direct=<dev>` (BlackBox's macvtap); HQ may use another sub-key.
