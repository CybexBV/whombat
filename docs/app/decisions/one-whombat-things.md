# One Whombat — things and server pages (stream WT, 2026-10-17)

Stream WT of the one-Whombat build (Whombat `docs/implementation/one-whombat/assignment.md` §7.2; product decisions
ONE-11…ONE-15 in Whombat `docs/decisions/one-whombat.md`). Servers in the web app: the server page (mock 2) with its six
tabs, the guest page with editing, consoles, Add a server, “Ask about <server>”, Home's Servers card, and the hosts
client models shared with Android. Ported from Rackoon's React UI (`hosts/web/src`), restyled to Whombat's
tokens and type, English only. Contracts 0.80.0 (`api.hosts.*`, topic `hosts:<burrowId>`).

| # | Decision | Why |
|---|---|---|
| AP-1300 | **`/things/:thing`** (`ThingScreen`, props `burrow` and the decoded thingId as WS's route passes them): `servers` is the servers list, `server:<id>` a server's page, `connection:` and `device:` open their existing page in Settings → Connections (`connection=<catalogId>&id=<con_…>`, replace). | One route for every thing; connections and devices already have a page with tools, tiers and limits, so no second one. |
| AP-1301 | **`@whombat/client/hosts`** holds the pure parts (formats, levels, chart arithmetic, view models, configuration rules, console frames, refusal words, the create forms' keys, realtime patches); **`@whombat/client/hosts/react`** the hooks; **`@whombat/client/hosts/fixtures`** the fixture world. Not re-exported from the package root. | Android (stream MA) reuses the same models; the root already exports the box status's `host` module, whose names (`HostSeries`, `formatBytes`) would collide. |
| AP-1302 | Numbers read as the mock spells them: a no-break space before `%` and `°C` (“10 %”, “75 °C”), “76 / 118 GB”, guests' memory “3.1 / 4 GB”, an em dash for no data, server CPU whole, guest CPU one decimal. Rackoon's formats otherwise, English only. | Copy is the mock's; the no-break space keeps the figure on one line. |
| AP-1303 | One hook per hosts read (`useHostServer`, `useHostManageRead`, …) and **`useHostsChange(ep)`** for every write, which refetches the reads that write touches when it went through; `useChangeRunner` turns the outcome into words (done, “needs an approval first”, a missing key, a refusal). | Writes are commands that can be approved or blocked; screens never repeat that handling. |
| AP-1304 | **Live**: the things screens and Home's card subscribe to `hosts:<burrowId>` themselves (`useHostsLive`). `hosts.server` replaces the server's row in the fleet in place (and refetches the page and totals); `hosts.guest` moves the guest's dot everywhere at once, then the numbers refetch; alerts, tasks, enrollments and `hosts.resync` refetch what they touch (`hosts/apply.ts`, called from `query/apply.ts`). | Bootstrap topics may not list `hosts:`; patching what the frame carries makes power changes feel instant. |
| AP-1305 | Charts on tokens: **`TimeChart`** (value words, dashed lines in their own colour, area wash, a dot on the newest point, crosshair and one tooltip, keyboard walk) and **`AreaSparkline`** (Home's “CPU · 24 h”) in `components/charts/`. The sparkline is not called `Sparkline`: the box status has one (a muted line with a dot). Temperature scales tick every 20° with the top 6° above the peak (mock 2: 40°/60°/80° under 90°). | WS moves the box status charts there; distinct names merge cleanly. |
| AP-1306 | Pages are CSS modules on tokens (`Things.module.css`); badge and notice tints are the status tokens mixed at the mock's alpha (`color-mix`), memory bars `--role-researcher` (the mock's `#8f7fc9`). | No hex in components. |
| AP-1307 | **Everything open is in the address**: `?tab=`, `?guest=` + `?gtab=`, `?console=host\|<guest id>`, `?ask=0`, `?chat=<id>\|new`, `?add=1`, `?q=`/`?state=` (guests list). `validateThingSearch` is there for the route. | Deep links, Back, and links from Whombat's chats. |
| AP-1308 | **Summary** is mock 2: open alerts first (with “Look into it” and “Remind me tomorrow”), the five figures, the CPU temperature over 24 h, the busiest guests with “All N guests”. Hints go to the tab they are about (Sensors, System) and to Watch, not on Summary. Every server gets all six tabs; a server without Proxmox backups says so on Backups. | The mock shows no hint box on a warm pve-02; one place per signal. |
| AP-1309 | **Home's Servers card** (no props, as WS's stub): absent when this Whombat has no hosts service; “Servers aren’t reachable right now.” on `hosts_unavailable`; “No servers yet. Add a server” when empty; otherwise the mock's table, problems first. | Home shows what the box has; the lead's 503 rule. |
| AP-1310 | Refusals show Whombat's server words as they are (SH already words the service's codes); `digest_mismatch` (`details.code`) reads “Changed meanwhile — review again.” and refetches the configuration, so the review shows the new old values; field errors go back to their fields. | One source of words; the assignment's copy for conflicts. |
| AP-1311 | **The five figures**: CPU (threads), Memory (`76 / 118 GB`, “64 % used”), Hottest (the hottest sensor, warn/bad by its limit; “warm for 17 h” counted back on that sensor's history while it is warm, else its name), Storage (Proxmox storages that hold guests' disks, else volumes, else disks; “44 % used”), Guests (“19 running”, “6 VMs · 13 CTs”). The chart shows the CPU sensor's history (else the hottest), the dashed line at 85 % of its limit (“warm from 72 °C”). | The mock's figures from what the contract carries. “overbooked” needs allocated-disk totals the contract doesn't have (gap for 0.80.1), so the line says how full it is. |
| AP-1312 | **Editing** a guest is Rackoon's: typed fields → a review listing `key  old → new` → Apply with the digest of what was reviewed; values start from the pending ones; a banner lists changes waiting for a restart with Revert and **Restart now** (asked first). Memory, processors, NICs, the CD drive, boot order, disk grow and move, name, start at boot, protection, notes, tags, guest agent, cloud-init user, password, SSH keys, DNS and addresses. | Nothing changes without seeing old → new; restarts always ask (ONE-12). |
| AP-1313 | **Power**: Start straight away; Shut down, Restart and Force stop ask in plain words (“Like pulling the plug: anything unsaved is lost.”); the server's own Restart and Shut down too. The new state arrives live. | ONE-12: stopping and rebooting always ask. |
| AP-1314 | The console transport is Rackoon's (virtual sockets per channel, pings, `activity` on real input, close reasons), opening Whombat's path with `whombat.console.v1` and `whombat.token.<token>`; the frame codec is in `@whombat/client/hosts`. | Proven code; the contract's subprotocols. |
| AP-1315 | **Consoles** open in a wide dialog over the page (not Rackoon's side panel). Text consoles use the AI sign-in's terminal (`features/ai/terminal.ts`: token colours, CSP-safe styles); VM screens noVNC; SPICE is never offered (ONE-13). Closing ends the session; a token that never reached its socket is closed at once. | The pane beside the page is the Ask pane; one terminal on tokens. |
| AP-1316 | On the **appliance session** (managed boxes reached through dev.whombat.com) the console dialog says “Consoles open on the local network for now.” instead of connecting; the buttons stay, everything else works. | There is no session stream for a console yet (contract gap); a plain sentence beats a button that fails. Lead's ask. |
| AP-1317 | **Ask about <thing>** is a `SidePane` (400 px) with the newest task chat about the thing (`chats.list` by subject), or a box that starts one (`chats.start` with the subject); “New chat” starts another, × closes it (`?ask=0`) and “Ask Whombat” in the header reopens it (`?ask=1`). It opens by itself only where it fits beside the page (≥ 1240 px, where `SidePane` stops overlaying). The chat is the messaging room in WS's task-chat look (`look="chat"`, passed untyped until WS's prop lands; make it a plain prop at merge). | Mock 2; the room brings cards, approvals and typing; no second chat UI. |
| AP-1318 | **Add a server** (on a Whombat with `hosts.install`, contracts 0.85, replaced by Sign in once and Run a command: `server-signin-web.md` AP-1677…) is `/things/servers?add=1` (also `add=server`): the install command made when the dialog opens (owners), copied with one button, valid an hour; the servers that ran it below, polled every 10 s, each **Add it** (with an editable name) or **Not this one**. Members are told only owners add servers. | Needs you's “Review” links here (told the lead); ONE-15. |
| AP-1319 | **Guest tabs**: Summary always; Hardware and Options for Proxmox guests with Manage on; Cloud-Init for Proxmox VMs with a cloud-init drive; Snapshots with Power on (not Docker); Backups, Firewall and Tasks for Proxmox with Manage on. Incus guests get Summary and Snapshots: Rackoon's raw Incus key editor is left out (rare here; Whombat changes Incus keys in a chat with `guest_config_set`). | The platform decides what exists, the switches what is listed. |
| AP-1320 | **Left out** of the port, each with its reason: Proxmox's appliance template catalogue (a download link does the same); bulk actions (one at a time, or ask Whombat); Replication and HA tabs (cluster-only and rare; the contract has the ops for Whombat); the Screens wall and thumbnails (no thumbnail route until 0.80.1); chart zoom and annotations (no annotations route); maintenance windows and uptime checks pages (Watch and Whombat cover them; the hooks exist); agent update buttons; Rackoon's assistant, users, kiosk and Dutch texts (ONE-13). | Ship the screens people use; the rest is reachable through Whombat. |
| AP-1321 | **Servers** (`/things/servers`): the Home table for every server, a notice when servers wait to be added (Review), open alerts with Look into it, and Add a server. Rackoon's capacity heatmaps and workload columns are left out: a server's page has them per server. | A list to get to a server, not a second dashboard (Home is that). |
| AP-1322 | New dependency **`@novnc/novnc` 1.7.0** (MPL-2.0, the unmodified npm package, loaded only when a VM screen opens); `THIRD_PARTY_NOTICES.md` regenerated. xterm.js was already a dependency. | Licences recorded as usual; MPL file-level copyleft is met by the unmodified package. |
| AP-1323 | Owners change servers, members view (Whombat's server enforces it, SH). The page shows changes to everyone and the server refuses members in plain words; only the switches, Remove and Add a server are hidden from members (`hosts.status.canManage`). | One rule, enforced once; members see what exists. |
| AP-1340 | **Fixtures**: the mock's five servers (pve-02 running hot with its 23 guests, blackbox's failed array, a server waiting to be added) as contract shapes in `@whombat/client/hosts/fixtures`, checked against the schemas in tests, answering the hosts routes and changing as you act (power, edits with digests, snapshots, firewall, enrollments, alerts). The web layer (`VITE_FIXTURE_HOSTS=1`) adds Whombat and the chat “Why is pve-02 so warm?”. | Visual checks and tests against the real shapes; Android can use the same world. |
