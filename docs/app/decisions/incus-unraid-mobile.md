# Full Incus, unRAID and QEMU on Android (AP-1617…AP-1646)

John, 2026-10-17: “Add The Titan as a server (install the agent). Then add full support for Incus and unRAID.”, then
“full QEMU support (through libvirt)”. Whombat decides what that means in `docs/decisions/incus-unraid.md` (IU-01…IU-13);
this is the phone's part, stream MA of `docs/implementation/incus-unraid/assignment.md`: IU-09 (the Incus instance
screen, the Incus and Unraid server screens, containers' Update and autostart, the self guest) and IU-13's phone part
(a libvirt VM gets the Incus instance's screen, a QEMU/KVM server its own), with IU-02, IU-06…IU-08. Contracts 0.83.0
(CT-363…CT-368) and 0.84.0 (CT-369, CT-370). It follows `proxmox-mobile.md` (AP-1485…AP-1502) wherever it can.
