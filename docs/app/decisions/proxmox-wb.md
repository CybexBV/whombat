# Full Proxmox support — guest lifecycle, backups, tasks, firewall, replication (stream WB, 2026-10-17)

Stream WB of the Proxmox build (Whombat `docs/implementation/proxmox/assignment.md` §3; product decisions PX-01…PX-11
in Whombat `docs/decisions/proxmox.md`). The guest page's header, Summary, Backups, Firewall, Replication and Tasks
tabs, the lifecycle dialogs, a server's Backups tab with its backup jobs, and the task tracker, ported from Rackoon's
`features/guest` and `features/manage` (`hosts/web/src`, `docs/MANAGE.md` §4). Contracts 0.81.0.

| # | Decision | Why |
|---|---|---|
| AP-1415 | **One task tracker for the whole app** (`features/things/tasks/`): `useManage` tracks every change that answers with a task and toasts “<What> started.” with **Show progress**; `HostTasks`, mounted once in the shell (`BurrowShell`, lazily), settles a task from the `hosts.task` frame (`taskId`) or by asking every 3 s when no frame came (no socket on that page, fixture mode, an older hub), then toasts how it ended once, refetches the server's reads and opens a created guest. Kept in memory for the session, at most 50. | PX-05; a task ends while the person is elsewhere, and not every page subscribes to `hosts:`. |
| AP-1416 | **Outcome words** (`taskOutcomeText`): “Backup of web finished.”, “… finished with 2 warnings.” (Proxmox's `WARNINGS: n`), “Clone of web failed: <the task's first line>.”; failures and warnings carry **Show log**. The started words come from `taskWhat(op, name)` (“Backup of web”, “Deleting web”, “Turning web into a template”), overridable per call (`what`). | CLAUDE.md: plain words; the log is one click away, never in the toast. |
| AP-1417 | **The task dialog appends** the log: it asks for the task every 1.5 s from `logNext` (`logStart`), follows the end unless the reader scrolled up, and has **Stop the task** while it runs. The Tasks tab and both toasts open the same dialog; while it's open its task gets no outcome toast (the dialog shows it). | Rackoon's `TaskDialog`; reloading 500 lines every poll flickered and lost the scroll. |
| AP-1418 | **Replication** is a guest tab only in a cluster (`guestTabs(…, { cluster })`, from `detail.proxmox.cluster`); its jobs come from `config.get`'s `replication` (target, schedule, rate, last copy or error); Add and Delete (`replication.add`/`delete`). A container's Hardware tab reads **Resources** (`guestTabWord`). | Proxmox only replicates between nodes; WA's ask, Proxmox's word. |
| AP-1419 | **Header**: the state badge (“Template” for a template), a `node <name>` chip in a cluster or when the node differs, the tag chips (the configuration's, fresh after an edit), and **More** (the shell's row menu: Back up now…, Clone…, Convert to template… — “Shut it down first” under it when running —, Move to another server… in a cluster, Delete…). A template has no Power. | Rackoon's `GuestHeader` and `GuestLifecycleMenu`; the shell's menu has the keyboard handling. |
| AP-1420 | **Delete** asks for the name, ticks “Also remove it from backup jobs, replication and HA” (`purge`) by default, is refused for a running or protected guest, and **leaves the page when its task ends well** (`whenTaskEnds`); Convert to template does the same. A delete done at once leaves at once. | Leaving before the task ends showed a guest that still existed; leaving after a failure hid the reason. |
| AP-1421 | **Clone**: full by default; a template offers **Linked clone** (default) or Full; a full clone picks a storage (“Same as the original”); the ID shows the next free one as its placeholder (empty sends none: the service picks). **Restore**: as a new guest (new ID, new MAC addresses by default) or over this guest (serious, refused while running; the request names the guest too, PX-08), to a storage (“As in the backup”), start after. | Rackoon's `CloneDialog`/`RestoreDialog`. |
| AP-1422 | **Back up now** picks a Proxmox Backup Server first, offers compression only for other storages (ZSTD, LZO, GZIP, None → `none`), notes default `{{guestname}}`, “Protect it”. | Rackoon's defaults; a PBS compresses itself. |
| AP-1423 | **Backups table** (`manage/BackupTable.tsx`), shared by a guest's and a server's Backups tab: Made (a shield when protected), Storage (“verified” or “check failed”), Size, Format (a lock when encrypted), Notes, then Restore… and More (Protect/Unprotect, Edit notes…, Delete…). Delete of a protected backup opens its dialog, which says why and can't be confirmed. A removed guest's backup restores only as a new guest. | One table, two tabs; the refusal said where it applies. |
| AP-1424 | **Backup jobs** (PX-03) on a server's Backups tab above the last run, only with runtime feature `hosts.backup_jobs`: Job (its comment, else “Every day at 02:00 to pbs”), Saves to, Covers (“All guests but win11-test”), Keeps (“Last 3 · 7 daily …”; null “The storage decides”, all 0 “Keep every backup”), Next run (Paused for a paused job); Run now (asked: what it backs up, and that old backups are cleared at the next scheduled run, not now; a job bound to another node says to run it there) and More (Edit…, Pause/Resume, Delete…). | The lead's notes on the service; a run that doesn't prune surprised people in Proxmox too. |
| AP-1425 | **The job dialog**: Runs (presets “Every day at 02:00”, “Every day at 21:00”, “Weekdays at 22:00”, “Saturdays at 02:00”, “Sundays at 03:00”, or Custom… with the calendar event typed), Save to (backup storages), On (every node or one, in a cluster), Backs up (all guests with Leave out, chosen guests, or a pool), How, Compression (not on a PBS; `0` is none), Keep (newest, daily, weekly, monthly; empty everywhere = the storage decides), notes template, comment. New jobs: 02:00, snapshot, zstd, keep 3/7/4/6, `{{guestname}}`. Edit sends only what changed, with the job's digest; a stale one says “Changed meanwhile — review again.” | Most homelab jobs are nightly; strict params (PX-08) refuse fields sent for nothing. |
| AP-1426 | **Add to a backup job** (a guest no job covers: its hint, its Backups tab, the Backup job row): pick a job — a job of chosen guests takes it in, a job of all guests stops leaving it out; a pool's or another node's job is shown but can't be picked, saying why — or **A new job for <guest>** (the job dialog with only it). Without `hosts.backup_jobs` the hint's way out is Back up now. | PX-07; the pool belongs to Proxmox. |
| AP-1427 | **Summary**: the `manageReason` line when Manage is off (owners get “Agent settings”, the System tab); this guest's **Proxmox hints with their way out** (`guestHints`, worked out from the guest as the hub does per server: no backup job → Add to a backup job, backup old or failed → Back up now, old snapshot → Open Snapshots, guest agent down → What to do, which highlights the guest agent row with how to install it; changes waiting for a restart only when the banner isn't shown); the four figures; **History** with CPU, memory, network and disk I/O and a range picker (1 h … 90 days); **Details** (system, addresses, disks with storages, runs on, last backup, the jobs that cover it, snapshots with the oldest's age, a lock, changes waiting with a link to the banner, HA with its status, the guest agent) beside **Notes** (Edit or Add through WA's `TextKeyDialog`, `description`). | Rackoon's `SummaryTab` and `GuestHistory`; a hint without a way out is noise (ONE-07). |
| AP-1428 | Chart units sit in the chart's label (“Network · Mbit/s”), the axis keeps short numbers; memory is charted in GB. Jumps to a row scroll the page's own column (`scrollToId`), never the window around the shell. | “40 Mbit/s” didn't fit the axis; the window scrolled the sidebar away. |
| AP-1429 | **Firewall**: a note when the datacenter firewall is off (how to turn it on), the switch with the policies in words and the allowed/filters and log levels, **Options…** (policies, DHCP, NDP, router advertisement, MAC and IP filter, log levels; only changed keys sent), rules with #, On, Direction, Does, Matches, Note and Move up / Move down (`moveTo`) and More (Edit…, Delete…); the rule dialog has Incoming/Outgoing/Security group, Does, Macro, Protocol, Interface (the guest's `netN`), From, To, ports (tcp/udp/sctp without a macro), Log, Note, on. Every change sends its digest; a rule's on/off sends the whole rule with `enable` as a boolean. | Rackoon's `FirewallTab`; the old toggle sent `enable: 1`, which the hub's boolean field refuses. |
| AP-1430 | **`useManage` takes `done`** (the toast when it was done at once) and **`what`** (a task's name), so a dialog says “The backup is protected.” instead of the op's generic word; `manageDoneText` (WC's) stays the default. | Plain words per action without editing another stream's file. |
| AP-1431 | **Fixtures** (`packages/client/src/hosts/fixtures-wb.ts`, chained in `fixtures.ts`'s return around WA's): two jobs on pve-02 (the nightly one leaves out what WC's world has in no job: minecraft, old-wp-staging, test-ct) and one on pve-01; an old snapshot and HA and replication on arnica-prod-nest-01, win11-test's guest agent down, paperless's old backup, cli-proxy-api protected, debian-template a template; backups, clones, restores, templates, deletes, firewall changes with digests, replication and jobs change the world; tasks grow their log per read and end after a few reads (a backup to `local` warns, a restore under a taken ID fails). A guest it doesn't know (WC's templates) passes on. | The fake world shows every flow; deterministic per read, wall-clock times so durations read right. |
| AP-1432 | **Superseded by** `docs/decisions/runtime-ci.md` RTC-02: the review shots no longer reached their screens and are deleted. Review shots: `apps/web/e2e-managed/wb-shots.spec.ts` (`WB_SHOTS=<dir>`, skipped otherwise), light and dark at 1440×900. | Stream WD's pattern; not baselines. |
