# The delegation card on the phone (AP-7730…AP-7742)

John, 2026-11-06: “Implement this fully.” The delegation card (Whombat `docs/decisions/delegate.md`, DLG-20…DLG-31) in
the phone's Chat: the tasks that finished well fold away, a row has its pull request and a ⋯, the pictures of what a
task changed open under it, and a thread with work going on doesn't offer Settle. Every word and every state comes from
the shared view (`@whombat/client` `delegationCardView`, `DELEGATION_WORDS`), so the web says the same; the card is
`ui/delegationCard.tsx`, what makes it act `screens/DelegationCard.tsx`, its data `data/delegation.ts`.

| ID | Decision | Why |
|---|---|---|
| AP-7730 | **Superseded in part by chat-threads-cards.md CTC-12: the folded line stays on the card; the finished tasks’ records are under Details.** **The tasks that finished well fold into one line** under the rest: a check in the rows' number column, “4 merged”, and a chevron at the end. The whole line is a 44pt button (`expanded`, “Show them” / “Hide them” as its hint) that opens to the same rows. | What needs the person stays in view; ten finished rows hid the two that needed a look. |
| AP-7731 | **Superseded by chat-threads-cards.md CTC-12: Pull request and the ⋯ are on the task’s record under Details.** **A row has Pull request and a ⋯**: Pull request is a quiet link where the task has one; Open in T3 Code and Stop this task are in the row's ⋯ (“More for …”), iOS's own menu on iPhone and the menu sheet elsewhere, titled with the task. Stop still asks first with the system's alert. No ⋯ when there is neither. The ⋯ sits at the end of the row's link line, under its state, in the same place on every row. | Three links per row made every row look urgent; a ⋯ that moved with the links was hard to find. |
| AP-7732 | **A task's pictures open under its row**: a quiet “2 pictures” with a chevron in its link line opens them as the council's final card draws them (`ui/cardPictures.tsx`: full width with their aspect ratio, the image viewer on a tap, how to read them, the numbered notes). The message's own file row leaves them out. | The task now takes the before and after pictures the council's builder took; they belong to the task they show. |
| AP-7733 | **A question the assistant answers itself is quiet**: “Asked Neo” (the assistant's name, from the card's author) in the working tone, the ring turning. Warn (the state and the number) is only for what needs a look: an OK in T3 Code, a problem, checks failing, not merged. | The person has nothing to do for a question the assistant answers; amber there taught them to ignore amber. |
| AP-7734 | **Waiting for checks has no turning ring**: “Waiting for checks” in the plain tone, its time still counting. Merging turns. | Its thread isn't at work while the checks run elsewhere, and it holds no place. |
| AP-7735 | **No Settle while work handed over goes on**: the thread's header, the long press and the Chat list's swipe ask `settleOffer`, which asks the shared `canSettle` with the thread's `handedOver` (as the server lists it, and the T3 Code hand-overs the phone already knows), so a thread with a council or tasks at work offers neither Settle nor its swipe; the swipe goes to More. | Settle showed on such threads and the server refused it. |
| AP-7736 | **The demo world shows every state** (`fixtures/delegation.ts`, `EXPO_PUBLIC_WHOMBAT_DELEGATION=offer`, `working` or `done`; `1` is `working`): seven tasks on the checklist; at work, two merged and folded, one waiting for checks with a picture, one merging, one whose checks keep failing and one that asked Neo; ended, four merged and one that didn't finish. The council's checklist (`council: true`) sits under its card in the council thread. The demo threads say `handedOver` while tasks work, and refuse to settle. | Every state without a box. |
| AP-7737 | **No new words**: the fold, the menu, the pictures, the progress line and “Asked …” are all `DELEGATION_WORDS`. | The phone and the web say the same. |
| AP-7738 | **A task's AI chip sits at its row's end**, beside the checkbox and not inside it, with “After 1” under it: “Default” in `mut` in a hairline while the task has no AI of its own, its AI line (“Claude Opus 5.5 · Extra high”) filled in `sf2` once chosen, two lines at most, 42% of the row at most. The chip is 24pt with slop to 44pt, read as “AI for … : …”, and off while a press is on its way. Only while the checklist waits on a Whombat that has it (`aiChoosable`). | A button inside the row's checkbox would be lost to a screen reader; at the end it keeps the titles their width. |
| AP-7739 | **The AI menu is a bottom sheet** in the chat's “answers with” sheet's language, reusing its parts: the title (“AI for task 2” over the task's title, “AI for every task” over “2 of 3 use this”), the model rows (✓, the company beside the model, the default first), the effort pills that wrap (the model's own default on until changed; none for the default or a model without efforts), the Fast row with its bolt, switch and “Quicker, uses more of your plan” where the model has a fast tier, then Cancel and Done side by side. It asks T3 Code what it runs as it opens: a spinner and “Asking T3 Code what it runs…”, or why it can't; Done is off until the models are there. | One way to choose a model on the phone; one sheet is less to learn than nested menus. |
| AP-7740 | **Hand over N is a split button**: a 44pt arrow part of the same primary button, 1pt apart, opens the menu for every task; it is off with Hand over (nothing ticked, or a press on its way). What the others get (“Others: GPT 6.1 Sol · High · Fast”) is a muted line under the buttons, since a phone has no room beside them. | The choice for every task belongs with the button that hands them over. |
| AP-7741 | **A choice shows at once**: the chip or the line changes as Done closes the sheet, held until the server answered and the thread was read again; refused, it goes back with the server's words or “Couldn’t change the AI. Try again.” as a toast. Done with nothing changed sends nothing. | As a tick does; the card follows by `message.updated`, which can come after the answer. |
| AP-7742 | **The demo world chooses too** (`fixtures/delegation.ts`): on the checklist, grouping the settings runs with Claude Opus 5.5 at Extra high and every task has T3 Code's default; T3 Code runs GPT 6.1 Sol (Low…Ultra, fast), Claude Opus 5.5 (Low…Max, fast off) and Claude Sonnet 5.5 (no fast tier); `delegations.setAi` answers as the server does (400 for an AI T3 Code can't run, 404, 409 once handed over). No new words: all are `DELEGATION_AI_WORDS`. | Both chip looks and the menu without a box; the phone and the web say the same. |
