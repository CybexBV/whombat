# Add a server by signing in once on the web (stream W, 2026-10-18)

Stream W of the Sign in once build (Whombat `docs/decisions/server-signin.md` SI-01…SI-13; brief
`docs/implementation/server-signin/assignment.md` §2.5 and “W — web”). Add a server gets the level up front and two ways
in, Sign in once and Run a command, with the job shown step by step. Contracts 0.85.0 (CT-373…CT-379). Changes AP-1318
(one-whombat-things.md) for Whombats that have `hosts.install`; older ones keep it as it was.
