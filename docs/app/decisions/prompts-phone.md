# The person's prompts on the phone (PRP-*)

John, 2026-11-12: the person's prompts (Whombat [prompts.md](../../decisions/prompts.md) PRL-01…PRL-10) on Android and
iPhone, from one codebase. Every visible word is the shared `PROMPT_WORDS` (`@whombat/client`), so the web says the same.
Code: `apps/mobile/src/data/prompts.ts` (pure), `data/usePrompts.ts`, `screens/PromptPicker.tsx`,
`settings/PromptsScreen.tsx`, `settings/PromptEditScreen.tsx`, `fixtures/prompts.ts`.

| ID | Decision | Why |
|---|---|---|
| PRP-01 | *Superseded in part by AP-9376 (chat-inbox-phone.md): Prompts is in the message box's “+”, not a button of its own.* **Two ways in, only in the person's own Chat** (`chatRoom` 'chat', its top level and its threads; not Feedback, guests or branch rooms): a `/` and one word as the whole draft lists the matching prompts (`promptsFor`) in a panel over the pill, and a Prompts button (a `/` in a square) beside the paperclip opens them all in a sheet. A space or a new line ends the `/` word, so a `/skill …` message still goes as typed. | Typing `/` is the web's way; the button is the way for someone who doesn't know it, and the pill already holds the composer's tools. |
| PRP-02 | **A prompt that isn't for a repository fills the draft**; nothing is sent. **One for a repository opens “Which repository?”**: T3 Code's projects, asked each time the sheet opens, the ones it ran on first with “Ran 3 days ago”, a search over titles and folders; a tap uses it (`prompts.use` with the room's conversation and, in a thread, its root), the draft empties, the list jumps to the end and a new thread opens as after a send. | The words reach the person's own message unchanged, and the result looks like what sending does. |
| PRP-03 | **Without T3 Code's projects the sheet says why** (`not_connected`, `unreachable`, or a failed ask) **with “Put its words in the message”**, which fills the draft. A failed use is the alert a failed send shows (the server's words, else `useFailed`). | The person can still use the words; a failure that only flashes by would be missed. |
| PRP-04 | **Settings → You → Prompts is a page beside Shared links**, drawn as that page is (large title, the intro, a card of rows): each row the title, the first line and where it last ran (“Ran 3 days ago · Fusebox”), opening the editor; New prompt under the card; “Bring back Whombat’s prompts” with its hint while a shipped prompt is gone or changed, asked first. `whombat://settings/prompts`; the web's `/settings?part=prompts` opens it. | The You group's other lists live on pages of their own; the editor needs the whole screen. |
| PRP-05 | **The editor is a page** (`PromptEdit`), as the council's: Title and Prompt fields to core's limits, “For a repository” and, on one, “Let it reshape the code” and “Merge into main when it’s done” (switches with their hints) and the AI row, which opens the delegation checklist's AI sheet (`DelegationAiSheet`, `delegations.models`; “T3 Code’s default” when none). Cancel and Save at the bottom, Remove (asked first) on a kept one, why it wasn't saved over Save, leaving with changes asks first. Save sends the ownership switch, the merge and the AI only on a prompt for a repository. | The AI sheet is a sheet; a sheet from a sheet doesn't work on iPhone, so the editor can't be one. |
| PRP-06 | **A new prompt starts as for a repository; one saved from a message starts as not**, titled by the message's first line (`promptTitleFrom`). | Whombat's prompts are all for a repository; a message's words are most often something to send again as they are. |
| PRP-07 | **Save as prompt is in the message menu of the person's own messages in their Chat**, both menus (the sheet on Android, iOS's own menu with `text.badge.plus`, from the same `messageMenu`); it opens the editor filled, and after saving goes back to the chat with the toast “Saved to your prompts”. | One rule for both platforms; the person keeps something they wrote without retyping it. |
| PRP-08 | **A Whombat that doesn't know prompts (`unknown_op`) shows none**: no button, no `/` list, no menu item, no You row (the row also waits for the list's first answer). A link to the page then says the Whombat needs an update. | The feature isn't there; an error about it would be noise. |
| PRP-09 | **The demo world has them** (`fixtures/prompts.ts`): the starters, “Find what’s broken” run on Fusebox and Whombat, one of Mara's own not for a repository, T3 Code's four projects; `prompts.use` posts the message through the fixture server's own send. `EXPO_PUBLIC_WHOMBAT_PROMPTS=not_connected`, `unreachable` or `older` starts it in those states. | Every state can be looked at without a box. |
