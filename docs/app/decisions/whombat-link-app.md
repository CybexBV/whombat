# Whombat Link in the apps (AP-9500…AP-9529)

2026-11-18, phase 1 of Whombat [whombat-link.md](../../decisions/whombat-link.md) (LNK-04, LNK-06, LNK-06a, LNK-08,
LNK-14, LNK-36, LNK-40…LNK-44), against contracts 4.4.0. Shared code: `@whombat/client/managed` (`whombat-link.ts`:
the Reach rows, the Link-ended banner, the setup's steps, the boxes this device knows and every word). The box page:
`apps/web/src/managed/BoxSetup.tsx`, `BoxRoot.tsx`, `LinkBanner.tsx`; Settings: `apps/web/src/features/machine/
ReachSection.tsx`, `useReach.ts`, `ManagedTabs.tsx` (“Updates from”). The phone: `apps/mobile/src/managed/
CommunityApp.tsx` (Join a Whombat), `ReachCard.tsx`, `useReach.ts`, `push.ts`, `usePush.ts`, `ApplianceRoot.tsx`.

| ID | Decision | Why |
|---|---|---|
| AP-9500 | **One setup on a box's page** (`BoxSetup`, replacing the community and the own-address setups) for every unclaimed box that takes a claim on its page (`probeOwnClaim`): Claim your Whombat (the letters; at the own address with the `/c/` link) → Who are you? (name and email; Claim it) → at the own address Make its passkey, elsewhere Reach it from anywhere → Protect your Whombat (`ProtectPlaces`, with “Let {assistant} set it up” for a NAS it found) → Connect your AI, which the app runs (`/connect-ai`). `STEP n OF 5` in onboarding's frame. A box with the shared route still gets today's page. | LNK-40. The edition no longer decides the setup: every box is the same image (LNK-01), so the box's answer to a claim start does. |
| AP-9501 | **The old account link step (a code from app.whombat.com typed on the box, `account.link`) leaves the setup.** Settings keeps “Link to your Whombat account” only on a box before Link (`reach.get` answers `unknown_op`). | Link now starts on the box (`link.on`) and is confirmed at the account site (LNK-13); two ways to link would confuse. |
| AP-9502 | **Reach it from anywhere** (a box page that isn't its own address): on its Tailscale page, that Tailscale is on there; elsewhere Tailscale's controls (Turn on, own login server, its sign-in link). Once Tailscale is on, one line advises turning off key expiry for the box in Tailscale's admin console, with the reason. Then **Whombat Link once as a card** — “First month free, then €2.50 a month” from `LINK_PRICE_TEXT`, what it gives, Turn on Whombat Link and Not now. Turning it on shows the code and “Open app.whombat.com/link and enter ABCD-EFGH”, followed every 3 s until Link is on. Continue never waits for either. | LNK-14, LNK-40, LNK-41: an offer, never a gate. |
| AP-9503 | *In part superseded by AP-9527 (the Easy and Expert words).* **Settings → This Whombat → About → REACH** (`ReachSection`), before ADDRESS: Whombat Link in plain words (off with Turn on; starting with the code, the link page as a link and the time left, Cancel, New code once it ran out; waiting for an address; on with the free month's end and the account's email, Turn off asked once; ending on a date with what still works; ended), the address line only while the box has none (ADDRESS right below shows it), and Tailscale with **Turn on Tailscale** (opens the Overview's TAILSCALE). Nothing on a box before Link. | LNK-42; the words come from `REACH_TEXT` so web and phone say the same. |
| AP-9504 | *Its words are superseded by AP-9528 (Beta).* **“Updates from” in UPDATES**: a segmented Production · Development, one line on what each means (“New versions first, before they're fully tested. Something may break.”), and after a switch back to Production “This Whombat keeps <release> until Production has a newer version, then moves on by itself.” (`staysOn`). Only where the box answers `updates.channel.get`. | LNK-21, LNK-42. |
| AP-9505 | **The licence's PLAN section and its strip go** from both apps (web `SubscriptionSection`, `LicenceStrip`; phone `PlanCard`, the strip's licence banner). The licence code in `@whombat/client` stays for phase 2. | LNK-04: the licence is inert. |
| AP-9506 | **The Link strip** (web `LinkBanner`, phone's `useStrip`): while Link ends, “Whombat Link ends on <date>. Turn on Tailscale so you can still reach this Whombat away from home.”; after, “Whombat Link ended. This Whombat still works at home. Turn on Tailscale to reach it away from home.” Its **Turn on Tailscale** turns it on right there and then offers Tailscale's sign-in; once Tailscale is on the strip only says what still works. Asked on session open and every ten minutes. The Inbox items are the runtime's. | LNK-06, LNK-06a. |
| AP-9507 | **Remote help shows only while Link is on or ending** (web About, phone About); a box before Link keeps the old rule (none on a community box). | LNK-07. |
| AP-9508 | **A new phone install starts with “Join a Whombat”** (`JoinStartScreen`): Scan the QR code (the device link from the box's page, with its routes), or type its address (its own address or Tailscale name, `https://` and a trailing slash optional, `readBoxAddress`); the Whombats this phone joined open with one tap; “Sign in with a Whombat account” leads to today's cloud sign-in. Phones with a kept cloud session never see it. | LNK-08, LNK-44: no cloud account is needed to use a box. |
| AP-9509 | **Joining at a typed address**: the phone asks the box who it is at `https://<address>/v1/direct`, pins that PeerId on first use (`pinSource: 'box'`, as the box's own page pins it), then over an enrollment session to that address a device already in approves the phone (pairing), or the box's own screen shows a code for it (“Use its screen”). A box nobody claimed yet says to open its address in a browser first. | The address is HTTPS with a valid certificate, the same trust the box's page has. A box set up at its own address refuses code pairing, so its screen is the way when no link is at hand. |
| AP-9510 | **Push through the box** for a phone joined without a cloud account (`useManagedPush({ via: 'box' })`): its APNs or FCM token goes to the box (`push.token.set`); `registered: false` (Link off) reads as “no notifications to phones” with nothing to turn on, as does a box before Link; signing out clears it (`push.token.clear`). A phone signed in through the cloud keeps registering at control as before. | LNK-36. Both paths at once on one phone could deliver each notification twice. |
| AP-9511 | **Whether a phone's box has control behind it follows the phone's record, not the welcome's edition**: a box joined without a cloud account is the community shape (no control, push through the box); a box opened through the cloud account keeps control's parts. | LNK-01 makes the edition inert; a box saying “community” must not cut John's phones off control. |
| AP-9512 | **The iPhone shows no price, no sign-up and no way to buy** (`OFFER_LINK = Platform.OS !== 'ios'`): Reach says Link's state but offers no Turn on, no code, no app.whombat.com; the first screen and its words carry no price; a cloud account without a Whombat is asked to join one (“No Whombat here yet”), never sent to `/signup` or to choose a plan (on both phones). The phone never shows the Link offer card; Android turns Link on and off in Reach. | LNK-44; App Store rules. |
| AP-9513 | **The phone's switcher lists the Whombats this phone knows** (`knownSummaries`, `switcherRows(…, { local: true })`), each with where it opens; a cloud phone keeps its account's list. **The box's web page lists only itself**: its storage belongs to its own origin, so it can't know other boxes, and the switcher stays hidden there. | LNK-43. Each box's own address and Tailscale name is another origin; nothing on the box's page can read another's storage. |
| AP-9514 | **The fake box answers the 4.4 ops** (`reach.get`, `link.on/off`, `updates.channel.get/set`, `push.token.set/clear`; code `KXQM-PRTV`), and `faults.linkState(state, extra)` sets Link on the box target. Review shots: `LINK_SHOTS=<dir>` with `e2e-box/link-shots.spec.ts`, which replaces the step-5 and own-address box shots. | Visual checks and the box journeys without a runtime. |
| AP-9515 | **The code while Link starts is shown big in the mono face** (22 px in Settings, 26 px in the setup) under “Open app.whombat.com/link and enter”, with the time left; the link page is a link on the web and Android. | Read on one screen, typed on another. |
| AP-9516 | **The setup's Connect your AI is the app's `/connect-ai`**: the page goes there as the setup ends, as the hosted claim does. Its kicker: AP-9519. | One Connect your AI for both. |
| AP-9517 | **An entry that needs a secure address says so before it starts** (whombat-link.md LNK-S11). The web's tile gets View with “Needs a secure address”, its page the sentence instead of the form; the phone's row the same note without the Set up tag, its Connect screen the sentence. The words are `CATALOG_REASON_TEXT` (`@whombat/client/connections`), matching the box's refusal; on the iPhone the sentence names Tailscale only. | The same words before and after starting; no Link offer on the iPhone. |
| AP-9518 | **No plain-HTTP page code in the web app** (DC-20). `InsecurePageGate` (“I trust this network”), its remembered acceptance and software device keys are gone: `loadOrCreateEndpointKey` makes only non-extractable WebCrypto keys. A software key an older box's plain-HTTP page left is still refused (`weakKey`, Forget this browser). The phone's direct route has its own key store and is unchanged. | The box serves no page over plain HTTP, so the code could never run; refusing the old key keeps a key script can read out of use. |
| AP-9519 | **Connect your AI carries on the box setup's count** (“STEP 5 OF 5”, `boxSetupAiKicker`) on the box's own page (`managed.page`); the hosted claim keeps “CLAIM · STEP 3 OF 3”. | After “STEP 4 OF 5” a new count of three read as a restart; every way through the box setup has five steps. |
| AP-9520 | **The Link strip is a line in the shell's notice slot** (`LinkBanner` in `BurrowShell`'s `notice`, after the agents line, before the passkey lines): full width, a status dot, the words and “Turn on Tailscale” as a button (AP-9523). | Floating over the top, it covered the app's own top line (“You haven’t signed in…”). |
| AP-9521 | **Join's first screen has no kicker**: the Whombat logo sits right above “Join a Whombat”. | “WHOMBAT” under the logo said it twice. |
| AP-9522 | **A join that can't reach the box says so in its title**: “Can’t reach this Whombat” (`PHONE_COMMUNITY_TEXT.unreachableTitle`), at a typed address and with a link; the kicker keeps the step's name, the line under it what to check, then Try again. | The title repeated the step (“Join a Whombat” under “JOIN A WHOMBAT”) and hid what happened. |
| AP-9523 | **The Link strip's actions are normal buttons**: “Turn on Tailscale” and Tailscale's sign-in are the phone's `secondary` button and the web's small secondary `Button`/`ButtonLink`, not the quiet or link style. The connection's Try again and the app update stay quiet. | In muted words the one way in from away looked disabled. |
| AP-9524 | **“Needs a secure address” has a way forward**: “Get a secure address” (`CATALOG_REASON_TEXT.needsSecureAddressAction`) under the sentence opens This Whombat → About at REACH, where Tailscale and Whombat Link are turned on (web `/settings?tab=appliance&section=about#reach`; phone `WhombatAbout { at: 'reach' }`, scrolled to the card). | The sentence alone was a dead end. |
| AP-9525 | **A typed address keeps its port** (whombat-link.md LNK-08): the phone reads `https://<name>.<tailnet>.ts.net:4480/` as the box's page shows it; a name typed without a port is the box's direct port (4480, where it serves its Tailscale name), an own address 443 (the door). The port goes into the first `GET /v1/direct` and the saved record's route (`readBoxAddress` → `{ host, port }`, `addressRecord`). | The box serves its Tailscale HTTPS on 4480; the phone refused the address the page shows and dialed 443 for a bare name. |
| AP-9526 | **The box's “Whombat Link has ended” item names no place to subscribe** (LNK-44): it ends at “turn on Tailscale.”; the e-mail, the box's screen and the account site say how to subscribe again. | The box writes it once for every client, the iPhone app included, which shows no sign-up or place to buy. |
| AP-9527 | **Reach says Easy and Expert, as the installer does** (one-environment.md ENV-12; `REACH_CHOICE_TEXT`). The Link row has “Easy · Whombat Link” above its state; off, its line is the offer sentence (`LINK_OFFER_TEXT`) and “What you get” folds out the six points. The Tailscale row has “Expert · Tailscale or Headscale”, the line “You set up Tailscale on each of your devices.” and, while it is off, “What to know” with its two points. The setup's one-time Link card (LNK-40) is Easy's: its name, “Recommended”, the offer sentence and the points; it comes first, then Expert with Tailscale's controls. The iPhone shows the points but no price line and nothing to buy. | One choice in the same words everywhere; what Link gives is no price, so the iPhone may say it. |
| AP-9528 | **The development channel is called Beta** (ENV-03): “Updates from” is Production · Beta and “This Whombat takes Beta updates.”; on the wire and in the update repository it stays `development`. | People understand Beta; renaming the wire name would break every box. |
| AP-9529 | **The phone apps publish for production by default** (ENV-16): `publish-apk.mjs` and `publish-ios.mjs` take `--env prod` unless told `--env dev`, which stays until the move to production is done and goes with DEV; the iPhone script hands the chosen environment to the Mac by name. | One app for everyone; a forgotten flag builds the right one. |
