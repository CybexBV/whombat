# The person's prompts on web (PRW-01…PRW-12)

The web side of Whombat `docs/decisions/prompts.md`: `/` in Chat offers the person's prompts above the skills, a prompt
for a repository asks which T3 Code project, and Settings → You → Prompts keeps them. The words are `PROMPT_WORDS`
(`packages/client/src/prompts.ts`); the few the web adds are `PROMPT_WEB_WORDS` (`apps/web/src/features/prompts/promptsModel.ts`).

| ID | Decision | Reason |
|---|---|---|
| PRW-01 | **Prompts are offered in the person's Chat only**: the Chat room's composer and the reply box of a Chat thread (`screen === 'chat'`, a `dm` room; `chatRoom === 'chat'` in the thread pane). Feedback, task chats, channels and AskBox (`commandTool={false}`) show none. | `prompts.use` posts in the person's Chat; anywhere else the message would land in another room. |
| PRW-02 | **One `/` list, two groups**: PROMPTS first, then SKILLS, one listbox with a labelled group each; ↑/↓, Enter/Tab and Escape run across both. Without matching prompts the list is exactly the skills' list as before. Nothing matches either: “Nothing by that name.” (web word). | The person's own words are what they reach for most; one list keeps the keys simple and leaves the skills' behaviour alone. |
| PRW-03 | **A prompt row is its title and the first line of its words** (`promptPreview`), in the skills' row (title where the `/name` is, the line where the description is). | It reads like the rows around it and the first line says what the prompt does. |
| PRW-04 | **The repository picker takes the list's place** in the same popover: Back, “Which repository?” with the prompt's title under it, a search field that keeps the keyboard, the projects from `promptProjectRows` with “Ran …” on those it ran on. Escape or Back returns to the list; a new draft closes it. | Choosing stays in one spot and one hand on the keyboard; the search field holds focus so typing filters, as in the skill list. |
| PRW-05 | **Projects are asked only while the picker is open** (`prompts.projects`, 30 s fresh); an error reads as T3 Code unreachable. | It talks to T3 Code; nobody should wait on it before choosing. |
| PRW-06 | **Using a prompt clears the draft and opens its thread** as sending does: in Chat the new thread opens (`?thread=`), in a thread's reply box it is a reply there. Afterwards the prompts, messages and Chat threads are read again. A failure keeps the picker and the draft and says `useFailed` where the composer says send errors. | It should feel like sending a message, and trying again should be one key. |
| PRW-07 | **Without T3 Code** the picker says why (`PROMPT_WORDS.t3`) and offers “Put its words in the message”, which makes the prompt's words the draft. | The words are still useful; the person can send them to the assistant instead. |
| PRW-08 | **A box without prompts shows none, without an error**: `unknown_op` (or a 404/501 for the route) is “no prompts”: no PROMPTS group, no Save as prompt, and You's Prompts part goes from Settings, its home line and the account menu (`useYouParts`). While the list is still unknown the part shows, so nothing jumps on a box that has them. | An older Whombat is normal, not broken. |
| PRW-09 | **Settings → You → Prompts is Shared links' section**: the label with New prompt beside it, the intro, a card of rows (title, a quiet FOR A REPOSITORY tag, the first line, “Ran 3 days ago · Fusebox”). A whole row is the button that opens the editor. “Bring back Whombat’s prompts” with its hint shows under the card while a shipped prompt is missing or changed. | The same parts read the same; a list of things you edit opens on the row. |
| PRW-10 | **The editor is one dialog** (the plan dialog's language) used from Settings and from Save as prompt: Title, Prompt (tall text area, core's limits), the For a repository switch, and only with it “Let it reshape the code”, “Merge into main when it’s done” and the AI. Remove asks in place (“Remove “…”?” with Cancel / Remove) instead of a second dialog. A new prompt starts as for a repository; one saved from a message starts as not. Save sends `ownIt`, `merge` and `ai` only for a repository. | It works the same wherever it opens; a dialog over a dialog loses focus and context. |
| PRW-11 | **The AI is the delegation card's AI menu**, drawn inside the dialog and returning its choice to the draft (`onPick`) instead of sending it; its first row is “T3 Code’s default”. The button shows the model as T3 Code names it, its id while that list isn't there. | One menu for choosing T3 Code's AI everywhere; the prompt keeps its choice until Save. |
| PRW-12 | **Save as prompt is on the person's own messages with words** in Chat and its threads (not cards, not other people's); it opens the editor with the message's words and `promptTitleFrom` as title, and says “Saved to your prompts”. | What the person once typed well is what they want again. |
