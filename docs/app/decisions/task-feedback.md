# Task feedback: a server task as a live card that settles into a line (AP-4300…AP-4349)

John, 2026-10-21, on the Z13 desk Whombat: Neo installed Home Assistant's updates and nothing ever said whether they
worked. “We need to massively improve this feedback.” His go: “Implement fully”. Whombat
`docs/decisions/task-feedback.md` TF-10…TF-18 are the decisions; contracts 0.116.0 (CT-880…CT-899) the card kind `task`
(`TaskCard`), its helpers and words, and the `task_finished` trigger. This app's part is TF-10 on the web and Android:
the card in the thread the task was asked in. It follows card-settle.md (AP-730: active is a card, settled is one line
that opens it) and looks like the run line and the live run card (run-line.md AP-668, card-settle.md AP-733). There is
no mock for it.

## What the runtime must do for the client

- Post the card on a message by the agent in the task's thread, with the card's line as its text (`taskCardLine(card,
  startedAt)`, or the title): it folds into the card (AP-4302). Other words on the same message show above the card.
- When the task ends, change the card on that message and publish the whole message as `message.updated` on the
  conversation's topic, with a frame time after the message's last frame: the client drops an older frame for the same
  message. No new message for the end: the card turns into its line by itself, and the woken agent's reply (TF-12) is
  the conversation.
- `serverId` is the hosts service's id, the one Home's things use (`server:{id}`): the card's mark and its link find the
  server by it.
