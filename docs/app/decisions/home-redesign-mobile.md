# Home redesign on Android (AP-2250…AP-2299)

Stream M of the Home redesign, 2026-10-18: Whombat `docs/decisions/home-redesign.md` HR-20…HR-24 (and HR-03, HR-05,
HR-08 for Done recently) on the phone. John asked for the web Home's server experience on Android (every server with its
CPU line, memory and temperature) and a Home that shows every server, everything connected and the chats with the
assistant. The shared model is stream W's `homeSections` (`home-redesign.md` AP-2206…AP-2215); the wireframe is
`docs/design-handoff/home-redesign/proposed.html` (its Android column: order and content), drawn with the phone's own
cards (`OneCard`, `OneRow`, mock 4 `../one-whombat/phones.png`), without highlight outlines. Contracts 0.91.0 (CT-403
`HomeChat`, CT-404 `ThingSummary.usedAt`).
