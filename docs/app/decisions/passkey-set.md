# Passkey setup (AP-6970…AP-6975)

Superseded by [shared-passkey.md SPK-07](../../decisions/shared-passkey.md#spk-07--one-default-setup-and-one-status): one default setup and one status on every entry point.

John, 2026-11-04: Settings offered “Add a passkey” although his Whombat had one. Devices → PASSKEYS listed it as a plain
row with an “Add a passkey” button that looked the same with none or five, and the Overview never said a passkey was
there. He asked for “Passkey set ✓” and “Add another passkey”, and for the passkey to be the backups' key by default.
