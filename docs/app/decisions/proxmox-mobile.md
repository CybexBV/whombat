# Full Proxmox support on Android (AP-1485…AP-1514)

John, 2026-10-17: “Implement full support for Proxmox.” Whombat decides what that means in `docs/decisions/proxmox.md`
(PX-01…PX-11); this is the phone's part, stream MA of `docs/implementation/proxmox/assignment.md`: PX-06 (a guest's own
screen instead of the power-only sheet, and a server's Backups), with PX-03 (backup jobs), PX-05 (long work reports
back) and PX-07 (hints with a way out). Contracts 0.81.0 (CT-353…CT-356). It narrows `one-whombat-mobile.md` AP-1367.

The phone's pure models are in `@whombat/client/hosts/mobile` (`packages/client/src/hosts/guest-mobile.ts`, tested), on
top of the shared `@whombat/client/hosts` rules (`guestTabs`, `powerActions`, `config.ts`, `errors.ts`, `format.ts`,
`manageDoneText`) and hooks. The screens are `apps/mobile/src/screens/GuestScreen.tsx`, `screens/guest/*`,
`screens/ServerBackups.tsx` and `screens/HostTasksBridge.tsx`; the followed tasks `data/hostTasks.ts`; the demo world's
part `fixtures/hostsManage.ts`.

| ID | Decision | Why |
|---|---|---|
| AP-1485 | **A guest has its own screen**, `Guest` at `things/:serverId/guests/:guestId`: the address carries the server's thing id (`whombat://things/server%3Apve-02/guests/pve%3A118`, parsed to `pve-02`), the params the server id. The web's `/things/server:pve-02?guest=pve:118` (and after a burrow) opens it; it is restored in the one-Whombat shell and watched on `hosts.getGuest`. A server's guest rows open it; the power sheet (`GuestSheet`) is gone, nothing else used it. | A guest is a place, as on the web (`?guest=`); one address scheme for both. |
| AP-1486 | **The header**: the name (28/700), its state as a dot and words, then kind and id and node (“Running · VM 118 · pve-02”), the tags as small mono pills; TalkBack reads it as one header. Under it the power as 44dp buttons that wrap: Start and Resume go at once (filled); Shut down, Restart, Pause and Force stop ask first in a sheet (“Restart web? It’s down for a moment.”), Pause too (“Pause web? It stops where it is until you resume it.”). A server that doesn't let power through says why instead. | PX-06 asks for every stop, shutdown, restart and pause to be confirmed; a start can't hurt. |
| AP-1487 | **More** (owners, Manage on, Proxmox): Back up now, Take a snapshot (when snapshots are listed), Clone, Delete. Back up now picks the storage (chips; a PBS first) and how (While it runs · Paused · Stopped); the web's note and Keep stay on the web. Clone takes a name and an id (empty: the next free one, said under the field); always a full copy. Delete asks to type the name, only while it is switched off (“Shut web down first.”), and purges. | The four lifecycle actions people do from a phone; Move to another node stays on the web (it needs the cluster's choices and a check of what moves). |
| AP-1488 | **Tabs**: Summary · Settings · Snapshots · Backups · Tasks, from the shared `guestTabs` (Hardware and Options are one Settings; Cloud-Init and Firewall stay on the web), and only while `manageable`; an Incus guest gets Summary and Snapshots. Manage off: the Summary alone, saying why (`manageReason`, else “Changing guests is switched off for pve-02.”). Members see the tabs without Change, More or Take; the Summary says “Only the burrow’s owners can change servers.” With five segments the control sizes each by its words at 13px (the rest of the width shared) instead of five equal parts. | PX-06's list; five equal parts cut “Snapshots” on a 368dp phone, and Android's shrink-to-fit didn't shrink them (checked on the emulator). |
| AP-1489 | **One sheet at a time**, each the one-Whombat sheet (`OneSheet`): what happens in a sentence, the action, Cancel; a refusal stays in the sheet as its note so the person can fix it and try again. | The approval sheet's language; stacked dialogs don't work on a phone. |
| AP-1490 | **Long work reports back (PX-05)**: a change that answers a task says “The backup of web started.”, is followed (`data/hostTasks.ts`, in memory for 24 hours) and says how it ended when the `hosts.task` frame comes or its read (every 3 s, beside the frame, which a sleeping phone can miss) ends: “The backup of web is done.”, “…, with warnings.”, “The backup of web didn’t work. Storage pbs is full.” (the service's words when short, else none). A power action only speaks again when it didn't work (its dot already moves). The bridge sits beside the navigator, so the note comes on any screen; a task that can't be read five times in a row is dropped quietly. | Plain words, no task id or log (CLAUDE.md); a restart of the app forgets, like the web's 24 hours. |
| AP-1491 | **How a change answers**: done at once says so (“Saved web’s settings.”, “Saved. web takes it at its next restart.”, “The backup is kept until you remove it.”); waiting for an approval or a key says the shared words in an alert and closes the sheet; a configuration changed meanwhile shows “Changed meanwhile — review again.” over the review of what is there now (the configuration is read again); field errors go back to the field. | `hostErrorInfo` and `commitOutcomeText`, the same as the web's `useManage`. |
| AP-1492 | **The Summary**: the four figures (CPU, memory, network, up), CPU and memory over the last 24 hours (`LineChart`, a finger or TalkBack's swipe reads a moment), NEEDS A LOOK with this guest's Proxmox hints and their way out (PX-07: no backup job → Add to a backup job, or Back up now on a Whombat without backup jobs; no recent backup, 8 days or a failed one → Back up now; changes waiting → Restart to apply; a snapshot older than 30 days → Snapshots; the guest agent not running is said with what to install, no button), WAITING FOR A RESTART (each value now → after, Restart to apply), BACKUPS (the last one, whether a job covers it, Back up now, Add to a backup job), its notes, and ABOUT IT. | The hub's own thresholds (`model/hints.go`), applied to the one guest the screen is about. |
| AP-1493 | **Settings, read**: Processors, Memory, Disks, Network, Options as the configuration is, a value waiting for a restart after an arrow (“4 GiB → 8 GiB after a restart”), unused disks listed, a key Proxmox keeps to itself shown with “Change this in Proxmox” and no Change. Under them “Adding hardware, firewall rules, HA and replication: on whombat on the web.”, a link to the guest's Hardware tab on the web where there is one (not in the demo world). | PX-06; the reading helps even where the change needs the web. |
| AP-1494 | **The everyday edits**: name, memory (MiB, at least 16), cores (1–512), start with the server, protection, notes and tags (spaces between them), each a sheet: its field, then the review in words (“Memory  4 GiB → 8 GiB”, Yes/No for flags), then Apply with the digest. **Grow** a disk: by how many GB (“Then 72 GiB”), the review of its size now and after, then Grow; no digest is sent (the service's resize route takes none, and Proxmox refuses to shrink). | The edits people make from a phone; the review is the web's safeguard, so it is the phone's too. |
| AP-1495 | **Snapshots**: newest first (“Taken Thu 14:02 · with memory”, its note), Take a snapshot (a name, `before-2026-10-17` by default; a note; for a running VM “Include what’s in memory”). A snapshot's sheet: Go back to it or Remove it, each asked (“Take web back to “weekly”? Everything that changed on web since then is lost.”). | The web's words (`SnapshotsTab`). |
| AP-1496 | **Backups**: Back up now and the list, newest first (“Today 02:02”, size, storage, kept). A backup's sheet: Restore as a new guest (a new id, Start it afterwards), Restore over this guest (asked, only while switched off; the request names the guest as well as its params, PX-08), and Keep it until I remove it / Stop keeping it (`backup.update` `protected`). | PX-06; restoring needs a decision, so it is two steps. |
| AP-1497 | **Tasks**: what ran, newest first, in words (Backup, Restore, Clone, Grow a disk…) with how it went; a task's sheet shows its log, read again every 2 seconds while it runs, with Stop it (owners). | PX-06. |
| AP-1498 | **A Proxmox server's Backups segment**: the last run and the next (the server's page), BACKUP JOBS on Whombats with `hosts.backup_jobs` — when it runs in words (“Every day at 04:00”, “Saturdays at 02:00”), where to, what it covers (“Every guest but win11-test”, “web, db and 1 more”, “The pool prod”), its next run or Paused — and LATEST BACKUPS (eight, by guest). A job's sheet: Run now (a task, PX-05) and Pause it / Resume it (`backupjob.update` with the job's digest). Making, changing and deleting jobs stay on the web, and the screen says so. | PX-03 on a phone: run and pause are the everyday actions; a job's schedule and retention need the web's form. |
| AP-1499 | **Add to a backup job** lists the jobs that don't cover the guest yet: a job of listed guests gets it added, a job of every guest takes it off its exclusions (both with the job's digest); a pool's job can't take a guest and says to add it to the pool in Proxmox. | Proxmox's three kinds of selection; the pool is Proxmox's own. |
| AP-1500 | **Hints open where they are fixed (PX-07)**: on a server's Summary a Proxmox hint opens its Backups (no backup job) or its Guests (no recent backup, changes waiting, old snapshots, guest agent); storage overbooked has no phone place (Storage is the web's). A Watch item whose link names one guest gets “Open the guest”. | The hub's hints are per server and list the guests; the guest's own screen has the button. |
| AP-1501 | **The demo world** answers a guest's screen (`fixtures/hostsManage.ts`, hooked into `fixtures/assistant.ts`): detail, metrics, configuration with a digest, choices, snapshots, backups, tasks and two backup jobs; `config.set` applies (a stale digest is refused), the other changes start a task that ends 2.5 seconds later with its `hosts.task` frame, and power sends its frame too. | So the screen can be tried, and checked on the emulator, without a server. |
| AP-1502 | **Where the code is**: the pure models in a new `@whombat/client/hosts/mobile` (a package export, not a line in `hosts/index.ts`, so the web streams' parallel additions can't clash with its names). `data/servers.ts`'s helpers stay: none is a pure swap for a shared one (they spell “34%” and “3.5 of 4 GB” where the shared ones say “34 %” and “3.5 / 4 GB”, and say up time on other thresholds); `guestFacts` went with the sheet. | The brief: new shared helpers in new files, swaps only where nothing changes. |
