# How the box is doing (AP-1135…)

John, 2026-10-11: “I would like to see how the appliance is doing. I would like to see: CPU usage and the history, disk
space usage, network utilization, so bandwidth, how many data has been sent and received today in megabytes/gigabytes,
perhaps a complete overview with token usage even.” He approved the mockup (a new first section of Settings → This
Whombat) with “Yes please”. Whombat `docs/decisions/box-status.md` BS-01…BS-12 for the manager, the runtime and the
server; contracts 0.78.0 (CT-334: `HostMetrics` and the session op `host.metrics` in `@whombat/protocol/session`,
`spend.daily` and `SpendDaily`, feature `host.metrics`, the words and formats in `@whombat/core/text` `text/host.ts`).
This is the app side: the shared client code and the web (AP-1135…AP-1149); Android is AP-1150 and on. The mock is
`box-status-mock/mock.html` (light and dark); where it and the contracts' words differ, the contracts win.
