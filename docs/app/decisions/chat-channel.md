# Chat: one threaded room, Feedback beside it, Home called Dashboard (web and client, 2026-10-18)

The web app's and `packages/client`'s side of Whombat `docs/decisions/chat-channel.md` (CHT-01…CHT-23) on contracts
0.93.0 (CT-440…CT-448), against the mockup John agreed to (`docs/design-handoff/chat-channel/index.html`; its layout,
order and words; the app's tokens and component sizes win on details, its figures are made up). Stream W
(AP-2400…AP-2449); the phone is stream M, whose decisions join this file (AP-2450…AP-2499). This replaces the task chats of
`one-whombat-shell.md` (AP-1260, AP-1270, AP-1273) wherever the runtime has `chat.channel`; without it they stay.
