# A service's settings on the phone (AP-7050…AP-7059)

Whombat's `docs/decisions/service-settings.md` (SST-01…SST-11) is the spec; the visual reference is the mockup
`service-dash-v2` screen 6 (the phone's Plex settings and the Change sheet). These are the phone's own choices around
it. The code: `apps/mobile/src/data/serviceSettings.ts` (pure), `screens/thing/Settings.tsx`, `screens/ThingPageScreen.tsx`.

| # | Decision | Why |
|---|----------|-----|
| AP-7050 | **A settings group is a section label over its card**, as the mockup draws it, not a label inside the card like the other panels: the group's title in the label face, its Ask on the right, the rows in one card, 56dp each. | The mockup's grouped list; a settings tab is a list, not a dashboard. |
| AP-7051 | **A row with choices shows the current choice's own label** (“8 Mbps”), the row's `value` (“Up to 8 Mbps”) only when the value is none of the choices. Switch rows show no words, only the switch. | The mockup's phone words; the web keeps the longer ones where there is room. |
| AP-7052 | **A switch flips at once** and shows its new state until the next read, through the page's control guesses (keyed `setting:<id>` beside the controls'). **Change it** closes the sheet and the row keeps its old value with a spinner until the service has said it took the change; then the toast says so. | Done means checked (SST-02): only a switch is allowed to look changed before the answer, because flipping back undoes it. |
| AP-7053 | **A setting the viewer may not change** keeps its switch greyed (a press says why, as disabled buttons do); a row with choices still opens its sheet so the choices can be read, with Change it disabled and the reason under it. | The value and its choices are worth seeing on Look only too. |
| AP-7054 | **Put it back** is in the press toast when the answer says `undoable` (the app's own toast with a button, also on Android, where plain toasts stay Android's), and in the Change sheet under the sentence while the row's `changed` has a `changeId`. Both run `changes.undo`, then read the page again; a refusal is said in the server's words. Success says “Put back.” | SST-03, with the smallest change to the toast: its button already existed for Undo. |
| AP-7055 | **A card's Ask is a small bordered “Ask” in the card's head** (the web's look), for every panel kind that draws a titled card: the panel renderer passes it to `OneCard` through a context, so each card kind gets it without its own code. It opens a sheet titled “Ask {assistant} about {title}” with the questions and “Or ask something else…”, each opening the Ask sheet with that question (or nothing typed). The mockup's long press on a group isn't built: a press that nothing shows is hard to find. | One way to ask about any card, findable by looking. |
| AP-7056 | **Whatever a sheet opens comes once it is down** (iOS's `onDismiss`, or 600 ms on Android, which has no such event): “Ask {assistant} instead”, a card's question. | iOS shows no new sheet under one it still shows. |
| AP-7057 | **The verdict takes the badge's place under the name**, beside the same status dot (15/1.4, `ink2`, up to three lines); a page without one keeps its badge. | The mockup shows the sentence alone; the dot still carries the status. |
| AP-7058 | **The phone has no server Storage view**, so “What uses the space” (SST-11, `spaceUse`) stays on the web for now. | A server's Storage is a web tab; the phone's segments are Summary, Guests, Backups, Array and Plugins. |
| AP-7059 | **The demo world has Plex's settings** (`fixtures/plexSettings.ts`): the server's tab, Ask on Now playing and Libraries, the verdict, the checked `setting` action and Put it back, so the screens can be tried without a Plex. | The other service pages are in the demo world too. |
