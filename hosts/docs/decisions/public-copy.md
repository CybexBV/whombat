# Working in public (2026-11-15)

The hosts service is public and its maintainers work in it directly. These rows were written when it was a repository
of its own; since the one repository it is the folder `hosts/` of `github.com/CybexBV/whombat` (Whombat
`docs/decisions/one-repo.md`), so “this repository” below is that folder, and the policies the rows name
(`CONTRIBUTING.md`, `SECURITY.md`, `TRADEMARKS.md`, the contributor agreement) are the root's since OR-71. It follows
Whombat's decisions
PUB-01…PUB-16 (Whombat's `docs/decisions/public-copy.md`). What differs here:

| # | Decision | Why |
|---|---|---|
| HPC-01 | **Everything that helps someone work on the code is here**: `NOTES.md`, `docs/decisions/`, the design hand-off (`docs/handoff/`), the guide for coding agents (`AGENTS.md`) and fast-test's recipe (`.fast-test.json`, `scripts/fast-test-prepare.sh`). The maintainers' test environment (nested Proxmox and libvirt on their own servers) and their agents' maintainer guide live in their private whombat-ops (John, 2026-11-15). | The notes and decisions explain the code and the hand-off is what the UI was built from; the test environment only describes private machines. |
| HPC-02 | **Private values were cleaned in the source** with Whombat's made-up values: the home network → `10.100.0.0/16` address for address (also the PROXY v2 test's binary form), Home's device id → `wb-3fkq-8mzt-2049`, the fake shell's user → `jdoe`, a mock WAN address → `203.0.113.50`, and comments and test names that described the maintainer's machines say what they are instead. The maintainers' private guard list checks every commit, push and release for the old values. | One mapping keeps every fixture and the test reading it in step; the guard list keeps the old values out. |
| HPC-03 | **Kept as they are**: the fixture servers `thetitan`, `blackbox`, `pve-02` and their kin, BlackBox as the unRAID server the sanitised testdata came from, and `io.thebeast.agent-resource.*`, the label keys of the agent-resource tool `TestPlaceRealDocker` runs under. | They are the fixtures' seed world (Whombat keeps the same names); the label keys are that tool's API, and the test only runs inside it. |
| HPC-04 | **No Biome and no `pnpm notices`**: the formatter is gofmt, and `THIRD_PARTY_NOTICES.md` is written by hand; its “Included in this repository” table names only paths the repository has. | This repository's tools. |
| HPC-05 | **A commit's version is “0.0.0-<UTC commit time>.<short revision>”**, the one the appliance's `nix/packages/hosts` gives it. | The repository has no release tags. |
| HPC-06 | **Public CI runs only on GitHub's runners**: `.github/workflows/public-ci.yml` runs `make ci` and a secret scan of the new commits (gitleaks with `.gitleaks.toml`, trufflehog with `.trufflehog-exclude.txt`), actions pinned by commit, a read-only token and no secrets; the maintainers' own CI never runs a fork's pull request. | Whombat PUB-16: outsiders' code never runs on the maintainers' machines. |
| HPC-07 | **Cybex BV holds the copyright** (John, 2026-11-15): `LICENSE`, the README's licence, `THIRD_PARTY_NOTICES.md` and `TRADEMARKS.md` name it. The tests' and docs' actor is “John Doe” (`John Doe (pe_1)`), Whombat's made-up person (its PCV-02). | The holder is a company. |
| HPC-08 | **Issues and pull requests are welcome**, under the contributor agreement (`CONTRIBUTING.md`, `docs/legal/contributor-agreement.md`); a pull request is merged here once `public-ci` and the maintainers' `guard` check pass. | John, 2026-11-15. |
| HPC-09 | **Superseded by Whombat one-repo.md OR-16** (the hosts service is the folder `hosts/` of the one public repository, `CybexBV/whombat`, and the appliance builds it from there). It starts from one root commit whose tree is the cleaned private `main`; the history before it stays in the maintainers' private archive. | Whombat PUB-01. |
| HPC-10 | **The first report tracker's name and its old marks never come here** (Whombat `report-trackers.md` TA-128): the guard list's “repository-wide” rules, checked with the rest of the list at every lint (`scripts/check-forbidden.sh`: `make lint`, `fast-test`'s `forbidden` step) and in what `make hub` and `make deb` build (`scripts/scan-artifacts.sh`). Without the list (contributors, public CI) both skip. | The same guard in every public repository. |
| HPC-11 | **The texts say what is registered**, as Whombat PUB-17: the name “Whombat” is filed as an EU trade mark (pending); the logo, the mascot and the app icons are not registered. `docs/legal/name-and-marks.md` (version `2026-11-20`) and `TRADEMARKS.md` say so. | Only the word mark was filed. |
