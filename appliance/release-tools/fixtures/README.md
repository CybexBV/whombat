# Development TUF fixtures

`dev/` is generated by `go run ./release-tools/cmd/tufrepo fixtures --out release-tools/fixtures/dev --at 2026-09-25T12:00:00Z`
(metadata valid for ten years from `verifyAt`, except where a case expires it on purpose). **Every key under
`dev-keys/` is a development private key** (`"development": true`); nothing here may be used for a real release.
The keys are kept outside `dev/` (which the VM tests serve over HTTP); prod refuses roots that trust them
(`dev-keys/README.md`).

`dev/fixtures.json` lists the cases, what to serve and the outcome a correct client reaches when verifying at
`verifyAt`; `release-tools/devtuf/fixtures_test.go` checks them with the real client code:

| Case | Serve | Expect |
|---|---|---|
| `valid` | `valid/metadata`, `valid/targets` | refresh ok, release `rt-fixture-1` resolves, its closure indexes verify, `assignment.json` verifies |
| `replayed-old-snapshot` | prime with `replayed-old-snapshot/newer`, then serve `…/older` | rollback refused |
| `expired-timestamp` | `expired-timestamp/metadata` | expired |
| `forged-target-hash` | `forged-target-hash/metadata` | signature (targets edited after signing) |
| `corrupt-download` | `artifact-cases/metadata`, `corrupt-download/targets` | artifact hash mismatch (the runtime's index) |
| `wrong-length` | `artifact-cases/metadata`, `wrong-length/targets` | artifact length mismatch (the runtime's index) |
| `rotated-root` | `rotated-root/metadata` with root v1 pinned | refresh ok through root v2 |

The device is provisioned with `pinned-root.json` (root v1). Regenerate with the command above; keys change on
every run (keep the old key ids in `helper/pkg/trust/devroot.go`: their private keys stay in the history).
`rt-fixture-1` is delivered by closure indexes with their blobs under `targets/nar/` (UP-X26; regenerated
2026-10-24, before it carried whole-closure artifacts).
