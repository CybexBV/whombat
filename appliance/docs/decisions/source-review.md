# Publishing the clients for review — decisions SR-nn

Decided with John on 2026-09-26. Whombat is commercial, but its privacy promise (the cloud and the relay carry
only encrypted bytes they can't read) is only credible if people can check it. So the client side is published as
source-available, for review and audit, while everything that runs the service stays closed.

| # | Decision | Reason |
|---|---|---|
| SR-01 | **Published: whombat-app and whombat-contracts.** Closed: control, the relay, the appliance and the Whombat monolith. | The clients do the encryption and hold the keys; contracts define the protocol and the claim ceremony. Auditors need both, and whombat-app vendors contracts. The relay is small, but publishing it mostly helps people run their own. |
| SR-02 | **Superseded by Whombat HE-63 (2026-10-24, licence.md LC-22): the two repositories are AGPL-3.0-only.** Was: **Licence: PolyForm Strict 1.0.0** with the required notice “Copyright 2026 John Pals (https://whombat.com)”, plus an **additional permission** for security and privacy research: change and run copies only to evaluate them, and quote excerpts or publish proof-of-concept code to report findings in good faith. `package.json` files say `"license": "SEE LICENSE IN LICENSE.md"`. Called “source-available”, never “open source”. Resolves D-01 for these two repositories; the four closed ones still need an explicit proprietary notice. | John's concern is people copying the product and using it for free: Strict allows only noncommercial use, no changes and no redistribution. The added permission is what makes an audit practical. Have a lawyer review it before the first push. |
| SR-03 | **Trademarks** stay reserved (`TRADEMARKS.md`): the licence grants no rights in the name, logos or mascot. | Standard for source-available products; the brand assets are there only so the software builds. |
| SR-04 | **Security contact: security@whombat.com** in `SECURITY.md` (acknowledge within 3 working days, assess within 10, fix critical within 30 and others within 90 days, coordinated disclosure, good-faith safe harbour). No pull requests (`CONTRIBUTING.md`). Partly resolves D-05 (security intake). | Inviting an audit without a way to report findings privately invites public disclosure instead. The mailbox must exist and reach John before the first push. |
| SR-05 | **Superseded by public-copy.md APC-01 (2026-11-14; Whombat PUB-01): each publish is one fresh-history snapshot commit, not a rewritten history.** Was: **Public mirror, not a public main repo.** Development stays in the private repos; `scripts/public-mirror.sh` clones the committed `main` with the release tags, removes the paths in `.public-exclude` from the whole history (`git filter-repo`, deterministic, so publishing again pushes fast-forward), and refuses to publish if an excluded path survives or gitleaks finds a secret (`.gitleaks.toml`, allowlist of reviewed fixtures only). Runbook: `docs/public-mirror.md` in each repository. | Keeps full history, which auditors want, while internal planning material stays private and nothing leaks by accident. |
| SR-06 | **Third-party notices** are generated (`pnpm notices`, `--check` in the release routine): bundled fonts (OFL-1.1, full texts next to the font files), the patched xterm.js (MIT), the Go module dependencies, and every production npm dependency. | The fonts and the patch are redistributed in the repository itself; the rest is a courtesy list for auditors. |
| SR-07 | **A public privacy and security model** (`docs/privacy-and-security.md` in whombat-app) says what is end-to-end encrypted, what metadata the cloud and relay see, what the appliance sees, and what a source audit can't prove: that the served web bundle matches the source, and what a vendor-pushed appliance update could do. | Honest limits are what make the published source credible; reviewers will ask these questions first. |

Not done (open): creating the public repositories (names, org) and the first push, which is John's call;
independently reproducible web and Android builds with published hashes (the web archive is already
deterministic on one toolchain, see whombat-app `docs/publishing.md`); a proprietary notice in the closed
repositories.
